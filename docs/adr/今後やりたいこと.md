# 各指標の詳細情報を表示したい

- 増配率（CAGR）の押下をした場合、実際の各年の配当金が表示され線グラフで繋がているようにしたい
- 連続増配年数についても、表示できる年数を縦並びでどのような変化があったのか表示したい


# 各ユーザーごとに銘柄リスト、銘柄ポートフォリオをくみたい
## 銘柄ポートフォリオログイン済みのみ可能
- 1ユーザー10ポートフォリオまで登録可能
- 1ポートフォリオを100銘柄登録可能
- 各銘柄ごとに保有数量、取得単価平均を保持
	- 保有数量から評価額を算出
	- 評価額と株価と数量から評価損益を算出
- 各ポートフォリオごとの配当の平均利回りを算出したい
	- 保有数量と利回りと評価額から利回りを算出
	- 保有数量と取得単価平均から取得単価利回りを算出
- 各ポートフォリオごとにスコア平均を算出したい
	- スコアは保有数量にかかわらず算出する

## 指標カスタマイズ
- ユーザーごとに各指標の評点を修正できる個人で設定可能（ログイン済みのみ可能
	- 選択する指標を5～10指標まで個人で選択可能
	- 各指標の1～10の指標を自由に設定可能とする
		- 各指標ごと
			- 増配率（5年CAGR）
				- 0.1%きざみ。
				- MIN0%
				- MAX50%
			- 連続非減配年数
				- 1年きざみ
				- MIN：0年
				- MAX：50年
			- 予想配当性向
				- 1%きざみ
				- MIN：-100%
				- MAX：500%
			- EPSの5年CAGR
				- 0.1%きざみ。
				- MIN0%
				- MAX50%
			- ROEの5年平均
				- 0.1%きざみ。
				- MIN0%
				- MAX100%
			- 配当維持可能年数
				- 1%きざみ
				- MIN：-100%
				- MAX：100%
			- 売上高の5年CAGR
				- 1%きざみ。
				- MIN：0%
				- MAX：100%
			- 営業利益率の5年平均
				- 0.1%きざみ。
				- MIN：0%
				- MAX：50%
			- MIX係数
			- 配当利回り
				- 0.1%きざみ。
				- MIN：0%
				- MAX：50%
