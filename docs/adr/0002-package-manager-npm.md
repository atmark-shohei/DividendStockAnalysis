# ADR-0002: パッケージ管理は npm を継続する（規約の pnpm から逸脱）

- ステータス: ✅ 採用（`.claude/CLAUDE.md` の記述からの意図的な逸脱）
- 日付: 2026-07-28

## 背景

`.claude/CLAUDE.md` は「パッケージ管理: pnpm」と定めているが、実測すると
**pnpm はこの環境にインストールされていない**（`pnpm -v` → not found）。
一方 npm 11.16.0 は動作しており、`package-lock.json` も既に存在した。

## 決定

**npm を継続する。** `.claude/CLAUDE.md` の pnpm 記述は、この ADR で上書きする。

## 理由

- パッケージ管理は軽量DDD の本質（レイヤ構成・依存の向き・不変条件）と無関係
- pnpm 導入は環境への変更（グローバルインストールまたは corepack 有効化）を伴い、
  ユーザーの確認が要る。移行の本筋を止めてまで通す価値が薄い
- npm は実測で動作しており、lockfile の履歴も連続する

## 影響

- コマンド表は `npm run ...` のまま
- 将来 pnpm へ移す場合は lockfile を作り直し、この ADR を「置き換え済み」にする

## 補足

インストール時に `npm warn allow-scripts` が出るが、**workerd のバイナリは
プラットフォーム別パッケージ（`@cloudflare/workerd-windows-64`）に同梱されており、
インストールスクリプトを実行しなくても動作する**ことを確認済み。
不要なスクリプト実行を許可していない。
