## 0. 何が起きているか

スコア基準の出典が**2つあり、10指標すべてで食い違っている**。

|              | 出典                                                                          | 位置づけ                                                                       |
| :----------- | :---------------------------------------------------------------------------- | :----------------------------------------------------------------------------- |
| **SSoT**     | OneDrive「銘柄スカウティング」`docs/investment_scoring_requirements.md`       | [scoring-requirements.md](./scoring-requirements.md)。**本プロジェクトの正典** |
| **参考資料** | `high_dividend_10_indicators_scoring.md`（YouTube「高配当ラボ」解説のまとめ） | 2026-07-27 に提供された二次資料                                                |

`scoring-requirements.md` は「スコア表の数値・閾値は原文から一切変更していない。
投資判断に直結するため、変更はユーザーの明示的な決定を必要とする」と定めている。
したがって**参考資料を根拠に閾値を書き換えることはしていない。**

## 2. 特に効くもの

### 2.1 ② の定義の違いは閾値では埋まらない

**非減配**（横ばいを含む）と**増配**（増加が必要）は別の数え方。
配当を据え置いた年がある銘柄は、SSoT では年数に算入され、参考資料では
そこで打ち切られる。**閾値を揃えても結果は一致しない。**

旧実装は非減配で判定していた（SSoT 側と一致）。

### 2.2 ⑨ の CN-PER は SSoT に存在しない指標

参考資料では CN-PER が本命で、MIX係数は「ネットキャッシュが負で CN-PER が
算出できない銘柄」への代用と位置づけられている。SSoT には CN-PER が無い。

$$\text{CN-PER} = \text{PER} \times \left(1 - \frac{\text{ネットキャッシュ}}{\text{時価総額}}\right)$$

CN-PER を採用すると、⑥ で計算するネットキャッシュを再利用できる。
指標間の一貫性は上がるが、**時価総額が新たな入力として要る。**

### 2.3 ① と ⑤ の相違は §0.2 の判断に触れる

§0.2 では「① の表の穴（0%〜2% が抜けていた）は転記ミス」と断定し、
`0%〜2% → 1点` を補って訂正した。しかし**参考資料にはそもそも 1点・2点の行が
存在せず**、「3%未満 → 0点」で終わっている。

穴だと思ったものが、**元々そういう表だった**可能性がある。
⑤ ROE も同じ構造（参考は「4%未満 → 0点」）。

> 旧実装は `> 0 → 1点` を持っていたので、SSoT 側を裏付けてはいる。
> ただし旧実装も SSoT と同じ出典から作られている可能性が高く、独立した証拠にはならない。

### 2.4 ⑧ の金融業

参考資料は「営業利益の概念がない金融業（銀行・保険等）は**経常利益率**で代用」と
定めているが、SSoT に記載が無い。**現状の仕様では銀行・保険を採点すると
⑧ が `null` か 0点になる。**

## 4. 推奨

**(a) SSoT 据え置きを既定とし、②③⑥ の3点だけ個別に検討する。**

理由。

- SSoT は本プロジェクトが「唯一の正解」と宣言した文書で、旧実装とも整合している。
  二次資料（動画の解説まとめ）で上書きする根拠としては弱い。
- ④⑦⑧ の相違は「参考資料のほうが緩い」方向で一貫している。
  **どちらが正しいかではなく、どれだけ辛く採点したいかの好みの問題**に見える。
  辛いほうを既定にしておくほうが、高配当銘柄の絞り込みには安全。
- 一方で次の3つは**good/bad ではなく明確な欠陥または未定義**なので個別に見る価値がある。
  - **②**: 定義の違いは好みではない。どちらの意味で数えたいかを決める必要がある
  - **③**: 相違は 65〜70% の1行だけ。参考資料のほうが単純（60〜70% で一括）
  - **⑥**: 参考資料の 1〜2年の穴は明らかな欠陥だが、
    **「0年未満 → 0点」が表に明記されている点は §0.3 の判断を裏付ける**

**⑨ の CN-PER は、⑥ を実装したあとに再検討する。** ネットキャッシュの計算が
動いてからのほうが、追加コスト（時価総額の入力）を正しく見積もれる。
