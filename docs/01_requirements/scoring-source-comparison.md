# スコア基準の出典比較と決定

> 作成: 2026-07-27 / 決着: 2026-07-27

> **この決定は [scoring-requirements.md](./scoring-requirements.md) の各指標表に反映済み。**

## 0. 何が起きたか

スコア基準の出典が2つあり、**10指標すべてで食い違っていた。**

|                  | 出典                                                                          | 位置づけ                                             |
| :--------------- | :---------------------------------------------------------------------------- | :--------------------------------------------------- |
| **正典（SSoT）** | OneDrive「銘柄スカウティング」`docs/investment_scoring_requirements.md`       | [scoring-requirements.md](./scoring-requirements.md) |
| **参考資料**     | `high_dividend_10_indicators_scoring.md`（YouTube「高配当ラボ」解説のまとめ） | 2026-07-27 に提供された二次資料                      |

`scoring-requirements.md` は「閾値の変更はユーザーの明示的な決定を必要とする」と
定めているため、**参考資料を根拠に自動で書き換えることはせず、5点を個別に決めた。**

## 1. 決定（2026-07-27）

| #   | 論点               | 決定                                                    |
| :-- | :----------------- | :------------------------------------------------------ |
| 1   | 全体方針           | **正典据え置き。** ②③⑥ の3点だけ個別に検討する          |
| 2   | ② 連続年数の定義   | **非減配のまま**（横ばいを含む）                        |
| 3   | ③ 配当性向 60〜70% | **参考資料に合わせ `60〜70% → 2点` に統合**（10段化）🔧 |
| 4   | ⑥ 下限帯 0〜2年    | **`0〜2年 → 1点` に統合。0点は債務超過のみ** 🔧         |
| 5   | ⑧ 金融業           | 🟡 **保留。** 実際に金融株を扱うときに決める            |
| 6   | ⑨ 主指標           | **MIX係数のまま確定。** CN-PER は将来拡張として記録     |

🔧 = スコア表が実際に変わったもの（正典と設計書の両方に反映済み）。

### 決定1: 正典据え置き（②③⑥ のみ個別）

①④⑤⑦⑧⑩ の相違はすべて「**参考資料のほうが緩い**」方向で一貫していた。
例: 売上成長 9% は正典で 5点、参考資料で 7点。

これは**どちらが正しいかではなく、どれだけ辛く採点したいかの問題**と判断した。
高配当銘柄の絞り込みでは辛い側を既定とするほうが安全なので、正典を採る。

### 決定2: ② は非減配のまま

正典＝連続**非減配**年数（横ばいを含む）／参考資料＝連続**増配**年数。
**定義が違うので、閾値を揃えても結果は一致しない。**

非減配を採った理由。

1. 旧実装も非減配で判定しており、過去の分析結果と連続性が保てる
2. 日本の高配当株はコロナ等で配当を据え置いた銘柄が多く、増配で数えるとそこで
   打ち切られて 0年になる。**減配耐性**を見る指標としては非減配が適切
3. 参考資料は「高配当・増配株投資」の枠組みで増配を数えるのが本来の意図だが、
   本プロジェクトが見たいのは減配耐性であり、目的が異なる

> 段階の粗さ（16年 5点 → 17年 10点）は認識したうえで、閾値変更は行わない。

### 決定3: ③ を 10段に統合 🔧

|          | 変更前（正典） | 変更後             |
| :------- | :------------- | :----------------- |
| 60%〜65% | 2点            | **60%〜70% → 2点** |
| 65%〜70% | 1点            | （統合）           |

65〜70% は本来かなり高い配当性向で低評価の帯であり、1点差の識別に意味が薄い。
表が単純になる利得のほうが大きい。

> ⚠️ **この指標だけ 10段**になる（他は 11段）。**1点を返す経路が無い**ので、
> 実装時に意図的なものだとコメントに書くこと。バグと誤認されやすい。

### 決定4: ⑥ の 0点を債務超過だけにする 🔧

|          | 変更前（正典）      | 変更後                        |
| :------- | :------------------ | :---------------------------- |
| 1年〜2年 | 1点                 | **0年〜2年 → 1点**            |
| 0年〜1年 | 0点                 | （統合）                      |
| 0年未満  | 表外（§0.3 で 0点） | **0年未満 → 0点**（表に明記） |

変更前は、**配当3ヶ月分の現金がある会社と債務超過の会社がどちらも 0点**になり、
実質的に異なる財務状態を区別できなかった。参考資料の「0年〜1年 → 1点 /
0年未満 → 0点」がこの問題を解いているので、参考資料側の穴（1〜2年の行が欠落）を
埋める形で採った。

**この指標の 0点は「債務超過」という明確な意味を持つ。**

> 参考資料に「0年未満（マイナス）→ 0点」が明記されていたことは、
> §0.3（負の値は 0点）の判断を独立に裏付けている。

### 決定5: ⑧ の金融業は保留 🟡

営業利益の概念がない金融業（銀行・保険）について、**正典に規定がない。**
参考資料は経常利益率での代用を定めているが、**実際に金融株を扱うときに決める。**

それまでの挙動: ⑧ が `null` になり、§0.5 により総合点で 0点として合算される。
つまり**金融株は自動的に 10点分不利になる。この状態で他業種と比較しないこと。**

決めるときの選択肢。

- (a) 営業利益が欠損していて経常利益があれば経常利益率で代用（**業種マスタ不要**）
- (b) 業種で判定して代用（業種情報の入手先が未定）
- (c) 代用しない

### 決定6: ⑨ は MIX係数のまま

参考資料では CN-PER が本命で、MIX係数は「ネットキャッシュが負で CN-PER を
出せない銘柄」への代用。しかし CN-PER は新たに**時価総額**（または発行済株式数）を
入力として要求し、現行の TSV/CSV 取り込みに含まれるか未確認。

MIX係数は PER と PBR だけで算出でき、**現行のデータ取得方式のまま実装できる。**

CN-PER は破棄せず、[⑨ の設計書 §9](../02_design/logic/mix-coefficient-scoring.md) に
**検討済み・未採用**として計算式・スコア表・必要な追加入力ごと記録した。
再検討の目安は ⑥ の実装後（ネットキャッシュの計算が動いてから）。

## 2. 指標別の相違一覧（記録）

決定の根拠として残す。各指標の詳細は `docs/02_design/logic/` の各設計書 §7 にある。

| 指標           | 相違の深さ      | 内容                       | 決定                           |

| ② 連続年数     | 🔴 定義が違う   | 非減配 / 増配              | 非減配のまま                   |
| ⑨ 割安度       | 🔴 主指標が違う | MIX係数 / CN-PER           | MIX係数のまま                  |
| ④ EPS CAGR     | 🟠 ほぼ全行     | 参考のほうが緩い           | 据え置き                       |
| ⑦ 売上 CAGR    | 🟠 ほぼ全行     | 同上。9% で 2点差          | 据え置き                       |
| ⑧ 営業利益率   | 🟠 ほぼ全行     | 同上。8% で 2点差          | 据え置き（金融業のみ 🟡 保留） |
| ① 増配率       | 🟡 下限側のみ   | 参考は「3%未満 → 0点」     | 据え置き                       |
| ⑤ ROE          | 🟡 下限側のみ   | 参考は「4%未満 → 0点」     | 据え置き                       |
| ⑥ 維持可能年数 | 🟡 1行          | 参考側に穴。0〜1年の点が逆 | **変更** 🔧                    |

| ⑩ 配当利回り   | 🟢 1行          | 1点の下限 3.25% / 3.0%     | 据え置き                       |

### 決定1 が §0.2 に触れる点（記録）

§0.2 では「① の表の穴（0%〜2% が抜けていた）は転記ミス」と断定して
`0%〜2% → 1点` を補った。しかし**参考資料にはそもそも 1点・2点の行が存在せず**、
「3%未満 → 0点」で終わっている。穴だと思ったものが元々そういう表だった可能性がある。

決定1（正典据え置き）により **§0.2 の訂正は維持する**。⑤ ROE も同じ構造。

> 旧実装が `> 0 → 1点` を持っていたことは正典側を裏付けるが、
> 旧実装も同じ出典から作られた可能性が高く、完全に独立した証拠ではない。

## 3. 実装時の注意

- **区分表は定数として1箇所に切り出す。** 出典の議論が再燃したときに
  再実装にならないようにする
- **③ は 10段**（1点を返さない）、**⑥ の 0点は債務超過のみ**。
  どちらも他の指標と挙動が違うのでコメントを書く
- ⑧ が `null` を返す金融株は、総合点で 10点分不利になる。
  有効指標数の併記（§0.5）でこれが読み取れるようにする
