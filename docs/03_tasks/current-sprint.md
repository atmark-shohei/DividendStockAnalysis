### T-007 スコア表の曖昧点を決着させる 🟢 完了（2026-07-27）

最大のブロッカーだったが、5点すべて決着。決定と根拠は
[scoring-requirements.md §0](../01_requirements/scoring-requirements.md) にある。
**その §0 が正**であり、各指標表より優先する。

| 論点              | 決定                                               |
| :---------------- | :------------------------------------------------- |
| §0.1 境界値の解釈 | 下限以上・上限未満（20% ちょうどは 9点）           |
| §0.2 ① の表の穴   | 転記ミス。0%〜2% → 1点 / 20%〜30% → 9点 に訂正済み |
| §0.3 負の値・赤字 | ③⑤⑥⑨ とも負なら 0点                                |
| §0.4 ③ の無配     | 0点（対象からは除外しない）                        |
| §0.5 データ欠損   | 総合点では 0点として合算、分母は常に 100           |

**スコアリングエンジン（F-10〜F-20）の実装に入れる。** 実装時の必須事項:

- 境界値ちょうどのテストを**全10指標ぶん**書く（§0.1 の規約をコメントに明記）
- 負値・無配・欠損の3系統をそれぞれテストする
- 個別指標は `null` を返せる型にする。総合点で 0 に丸めるのは集計時だけ
- 総合点の隣に**有効指標数を併記**する（⑥⑨ 未実装の間は最大 80/100 になるため）
