#### R-01 一覧の行クリックが効かない

- 原因: 押下中の「表示」ボタンが transform により自身の `::after` オーバーレイ（1211-1215）の包含ブロックになり、オーバーレイがボタンの箱まで縮む。
  `.metric-row-button` には打ち消し（1505-1507 `transform: none`）があるが、`.row-actions button:first-child` には無い。
- 再現: 一覧で銘柄名・総合点・配当利回りセルをマウスでクリック。mousedown は「表示」のオーバーレイ、mouseup はセルに落ち、
  click が共通祖先 tr/tbody に配送されて `rowActions.onSelect` が呼ばれない。16ms の短押しでも再現。
  「表示」の直押しとキーボード操作は動く。
- 修正案（効果確認済み）: `.row-actions button:first-child:active:not(:disabled) { transform: none }`

#### R-02 指標表の `›` / スコアバーで詳細が開かない

- 原因: hover 時の `transform: translateX(3px)` が td をスタッキングコンテキストにし、木順で先の `.metric-row-button::after` より上に描画される。
  `.score-bar-track { position: relative }`（1027-1029）もスコア列で同じことを起こす。
- 再現: 解析ダイアログの指標表で行末 `›` かスコアバーをクリック。ヒット対象が `td[aria-hidden]` / `.score-bar-fill` になり、
  `onRowClick` が呼ばれず `?metric=` が開かない。transform を打ち消すと発火することを確認済み。

#### R-03 「評価額」列が備考扱いで薄く小さくなる

- 再現: `/portfolio` の全保有行で評価額セル（`HoldingsTable.tsx:108`）が `--color-text-secondary`・13px・`min-width: 14rem`・折り返し可になる
  （実測 rgb(152,161,176) / 13px / 224px）。隣の現在株価は 14px・nowrap。表が約110px 広がり R-04 を悪化させる。
