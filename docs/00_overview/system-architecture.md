# システム全体構成

> ステータス: 🟡 draft — 技術選定が未確定。決まり次第このファイルを正とする。

## 目的

日本株の高配当銘柄を、利回り・配当継続性・財務健全性の観点から比較検討し、
ウォッチリストとして継続追跡できるようにする。

**やらないこと**: 投資判断の自動化、銘柄推奨、自動売買、他人への助言提供。

## データ源（確定）

外部 API・スクレイピングは**使わない**。ユーザーが手で持ち込む。

| 入力                 | 方式                                  | 出典想定               |
| :------------------- | :------------------------------------ | :--------------------- |
| 配当履歴             | 画面のテキストエリアへ TSV をペースト | IR BANK 等の配当履歴表 |
| 業績・財務・CF・配当 | CSV をドラッグ＆ドロップ              | 4ブロック構成の CSV    |
| 現在株価             | 数値を手入力                          | ユーザーが調べた値     |

詳細は [scoring-requirements.md](../01_requirements/scoring-requirements.md) §2。

この方式を選んだことで、当初懸念していたレート制限・利用規約・API 費用の問題は
発生しない。代わりに**入力データの正しさをユーザーに依存する**ため、
パーサー側の検証（欠損・単位・桁）がより重要になる。

> 🔴 **要確認:** 将来的に外部 API での自動取得へ移行する想定はあるか。
> 「あり」なら、いま `src/lib/external/` をインターフェースで分離しておく価値がある。

## 更新方針

- 株価・配当とも**ユーザーが入力したタイミングがすべて**。自動更新は行わない
- **入力（解析）した日時を必ず保存し、画面に表示する。** 古い入力値を
  最新として見せない

## 非機能の要点

詳細は `../01_requirements/non-functional.md`。ここでは全体に効くものだけ。

- 金額計算に浮動小数点を使わない（整数 or Decimal）
- 日時は UTC 保存・JST 表示
- 外部データは検証してから永続化
