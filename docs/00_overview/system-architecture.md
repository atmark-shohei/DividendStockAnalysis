# システム全体構成

> ステータス: 🟡 draft — 技術選定が未確定。決まり次第このファイルを正とする。

## 目的

日本株の高配当銘柄を、利回り・配当継続性・財務健全性の観点から比較検討し、
ウォッチリストとして継続追跡できるようにする。

**やらないこと**: 投資判断の自動化、銘柄推奨、自動売買、他人への助言提供。

## 非機能の要点

詳細は `../01_requirements/non-functional.md`。ここでは全体に効くものだけ。
