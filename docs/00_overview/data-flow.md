> ステータス: 🟡 draft

## 1. 銘柄データの取り込み

```
[外部データ源]
   │  ① 取得（レート制限を守る）
   ▼
[src/lib/external/*Client]
   │  ② スキーマ検証（欠損・単位・桁・日付）
   │     └─ 失敗 → 検証エラーログへ記録（捨てない）
   ▼
[正規化]  単位を統一（金額=銭単位の整数、日時=UTC）
   │
   ▼
[src/lib/db]  ③ UPSERT（銘柄コード＋日付の UNIQUE 制約で二重取り込み防止）
   │           fetched_at を必ず付与
   ▼
 [DB]
```

**要決定**: ①のトリガー（定期バッチ / 画面表示時 / 手動ボタン）

## 2. 画面表示

```
[ブラウザ] ── リクエスト ──→ [Server Component]
                                  │
                                  ▼
                          [src/lib/<domain>]
                            ・利回り計算
                            ・配当継続年数の判定
                            ・スクリーニング条件の適用
                                  │
                                  ▼
                            [src/lib/db] 読み取り
                                  │
                                  ▼
                   DTO（表示用の型）に変換して返す
                                  │
                                  ▼
              [components] 受け取った props を描画するだけ
```

- コンポーネントはデータ取得しない。計算もしない。**描画のみ**。
- 丸め処理は表示層の1箇所だけで行う。

## 3. ウォッチリスト操作

```
[ブラウザ] ── POST/DELETE ──→ [API Route]
                                   │ 入力検証（銘柄コード形式、重複）
                                   ▼
                             [src/lib/watchlist]
                                   ▼
                              [src/lib/db]
```

**要決定**: ユーザーの概念を持つか（認証あり）／単一ユーザー前提か
