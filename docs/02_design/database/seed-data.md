# 初期データ定義

> ステータス: 🟡 draft

## 目的

開発・テストで使う最小限のデータセットを定義する。
**実データをそのままコミットしない**（データ源の利用規約に抵触しうる）。

## 開発用シード

実在の銘柄コードを使うが、数値は**架空の値**にする。
実データと取り違えないよう、銘柄名に `（テスト）` を付ける。

### stocks

| code | name                 | sector       | fiscal_year_end_month |
| ---- | -------------------- | ------------ | --------------------- |
| 9999 | テスト商事（テスト） | 卸売業       | 3                     |
| 9998 | テスト銀行（テスト） | 銀行業       | 3                     |
| 9997 | テスト電力（テスト） | 電気・ガス業 | 3                     |

### dividends（テスト観点を含めたケース）

| code | fiscal_year | period | amount_sen | is_forecast | 意図                            |
| ---- | ----------- | ------ | ---------- | ----------- | ------------------------------- |
| 9999 | 2023        | annual | 15000      | false       | 通常（150円）                   |
| 9999 | 2024        | annual | 16000      | false       | 増配                            |
| 9999 | 2025        | annual | 17000      | true        | 予想値                          |
| 9998 | 2023        | annual | 8000       | false       | 通常                            |
| 9998 | 2024        | annual | 6000       | false       | **減配**                        |
| 9997 | 2023        | annual | 0          | false       | **無配（0とNULLの区別確認用）** |
| 9997 | 2024        | annual | 5000       | false       | 復配                            |

### stock_prices

| code | date       | close_sen | 意図                 |
| ---- | ---------- | --------- | -------------------- |
| 9999 | 2026-03-31 | 300000    | 利回り 5.33%         |
| 9998 | 2026-03-31 | 100000    | 利回り 6.00%         |
| 9997 | 2026-03-31 | 0         | **ゼロ除算の確認用** |

## 必ず含めるべき境界ケース

シードにこれらが無いとバグを取り逃す。

- [x] 無配（`amount_sen = 0`）
- [x] 減配
- [x] 予想値と実績値の混在
- [x] 株価 0（ゼロ除算）
- [ ] 株価データが存在しない銘柄（NULL / 行なし）
- [ ] 期末日をまたぐ配当
- [ ] 株式分割の前後
- [ ] 決算期変更（12ヶ月でない年度）
