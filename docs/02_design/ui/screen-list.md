## 全画面共通の要件

- ヘッダーにデータの**最終取得時刻**を表示する
- フッターに免責文言を常時表示する（投資助言ではない旨）
- スクリーニング条件・ソート順・ページ番号は **URL クエリに持つ**
  （リロード・共有・戻るボタンで壊れないこと）
- データ取得中はスケルトンを出す。レイアウトが飛ばないこと
- エラー時は「何が起きたか」と「次に何をすればよいか」を出す
