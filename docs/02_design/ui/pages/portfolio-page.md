## 1. 概要

**ログイン必須**（user・admin）。1ユーザーが最大10個のポートフォリオを持ち、
1ポートフォリオに最大100銘柄を保有数量・取得単価とともに登録できる。

**この画面がしないこと:**

- 集計の計算式そのもの（[portfolio-metrics.md](../../logic/portfolio-metrics.md) が正。
  この画面は計算結果を表示するだけ）
- 銘柄の詳細分析（保有銘柄の行クリックで [analysis-dialog.md](./analysis-dialog.md) を開く。
  ダイアログの中身はこの画面の責務外）
- 売買の記録・損益の確定（保有数量・取得単価の**手入力**のみ。取引履歴は持たない）

## 2. URL・状態

| パラメータ  | 意味                                                                               | 既定                         |
| :---------- | :--------------------------------------------------------------------------------- | :--------------------------- |
| `portfolio` | 表示中のポートフォリオID                                                           | ユーザーの先頭ポートフォリオ |
| `code`      | 解析ダイアログ（共通。[ADR-0014](../../../adr/0014-analysis-dialog-url-state.md)） | 無し                         |
| `metric`    | 同上                                                                               | 無し                         |

- ポートフォリオを持たない新規ユーザーは `portfolio` が存在しない状態になる。
  その場合は §6 の空状態を出す（既定値が無いのではなく「作る前」の状態）
- 保有銘柄の追加・編集（保有数量・取得単価。§5.1）のフォーム入力値自体は URL に置かない
  （一時的な編集state）

## 3. レイアウト

```
┌────────────────────────────────────────────────────┐
│ [メインNISA] [高配当コア] [成長ウォッチ]  ＋ 追加  3/10 │
├────────────────────────────────────────────────────┤
│ 評価額合計          評価損益                            │
│ 1,234,567 円        ▲ +82,340 円                       │
├────────────────────────────────────────────────────┤
│ 平均利回り(評価額加重)  取得単価利回り   スコア平均       │
│    3.42%                4.10%            68.2           │
├────────────────────────────────────────────────────┤
│ 銘柄  保有数量 取得単価 現在株価 評価額 評価損益 利回り スコア │
│ ── 最大100行 ──────────────────────────────────────  │
├────────────────────────────────────────────────────┤
│ ＋ 銘柄を追加                        42 / 100 銘柄       │
├────────────────────────────────────────────────────┤
│ 計算式の説明（§4 の式を文章化。透明性のための注記）        │
└────────────────────────────────────────────────────┘
```

- ポートフォリオ切替はピル状のタブ列。クリックで `?portfolio=` を更新
- 「＋ 追加」は10個未満のときだけ活性。上限到達時は `disabled`（no-op ではなく
  ボタン自体を無効化。追加できないことが視覚的に分かる必要があるため）
- 評価額合計は `--font-size-display`（38px）/700、評価損益は `▲`/`▼` ＋
  `--color-positive`/`--color-negative`（色だけに依存しない。§4.3）

## 4. 集計表示仕様

**計算式・丸め・ゼロ除算処理は [portfolio-metrics.md](../../logic/portfolio-metrics.md) が正。**
ここでは表示形式だけを定義する。

| 項目                     | 表示                                                                                              | 欠損時                                                                                                            |
| :----------------------- | :------------------------------------------------------------------------------------------------ | :---------------------------------------------------------------------------------------------------------------- |
| 評価額合計               | `<Money>`（円、3桁区切り）                                                                        | 保有0件なら「0 円」（`null`ではない）                                                                             |
| 評価損益                 | `<Money>` ＋ `▲`/`▼` ＋色                                                                         | 同上                                                                                                              |
| 平均利回り（評価額加重） | `formatMetricValue` 相当。小数第2位＋%。末尾に「（N銘柄）」を併記（`yieldEvaluableHoldingCount`） | 利回り・評価額のいずれか欠損の銘柄を母数から除く（[portfolio-metrics.md §3.3](../../logic/portfolio-metrics.md)） |
| 取得単価利回り           | 同上                                                                                              | 同上。母数は平均利回り（評価額加重）と同じ集合                                                                    |
| スコア平均               | 小数第1位                                                                                         | 保有0件なら `—`（0除算を「0点」と誤表示しない）                                                                   |

### 4.1 保有銘柄テーブル

| 列       | 内容                                                                                                                                                                                                    | 欠損時                                               |
| :------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :--------------------------------------------------- |
| 銘柄     | 名前＋コード                                                                                                                                                                                            | 常に非null                                           |
| 保有数量 | 整数                                                                                                                                                                                                    | 常に非null（入力必須）                               |
| 取得単価 | `<Money>`                                                                                                                                                                                               | 常に非null（入力必須）                               |
| 現在株価 | `<Money>`                                                                                                                                                                                               | `—`（銘柄が価格未入力）                              |
| 評価額   | `<Money>`（保有数量×現在株価）                                                                                                                                                                          | 株価が `—` なら評価額も `—`                          |
| 評価損益 | `<Money>` ＋ `▲`/`▼` ＋色                                                                                                                                                                               | 同上                                                 |
| 利回り   | `formatMetricValue`                                                                                                                                                                                     | `—`                                                  |
| スコア   | 総合点＋「（N/10）」（`<ScoreBar>` は使わない。一覧行と違い密なテーブルのため数値のみ。有効指標数の併記は省略しない。[scoring-requirements.md §0.5](../../../01_requirements/scoring-requirements.md)） | 総合点自体は常に非null（`score_cards` の必須カラム） |

行クリックは [search-page.md](./search-page.md) §4.1 と同じ **stretched button
パターン**で `?code=<コード>` を開く（[analysis-dialog.md](./analysis-dialog.md)）。

### 4.2 透明性の注記

design_mock の footnote（計算式を文章で説明する段落）を踏襲する。
「推奨をしない」立場を裏付けるため、集計方法を隠さない
（`.claude/CLAUDE.md`「投資判断そのものを自動化・推奨する機能は作らない」の裏返し。
計算根拠は常に開示する）。

### 4.3 P/L の色

評価損益にのみ `--color-positive`/`--color-negative` を使う。
**スコア・利回り・増配率には使わない**（[design-tokens.md](../design-tokens.md) §2.2。
色の役割は排他）。色だけで増減を表さず、`▲`/`▼` を必ず併記する。

## 5. 銘柄の追加・編集

- 「＋ 銘柄を追加」→ 銘柄コード・保有数量・取得単価を入力するモーダルフォーム
  （`<HoldingForm>`。**新しいダイアログ URL 状態は増やさない** — 既存の `?code=` と
  混同しないため、追加フォームの開閉はローカル state でよい。共有・直リンクの必要が無い一時操作のため）
- 保有数量・取得単価は数値入力（`<NumberInput>`。全角正規化・範囲検証。0以下は拒否）
- 100銘柄到達時は追加ボタンを disabled にする（§3 と同じ理由）
- 銘柄コードは [screen-list.md](../screen-list.md) の `COMPANY_CODE` 形式検証後に確定

### 5.1 保有銘柄の編集

- 保有銘柄テーブル（§4.1）の各行に「編集」ボタンを設け、モーダルフォーム
  （`<EditHoldingForm>`）で**保有数量・取得単価の両方を編集対象**にする
  （T-103 FEレビュー CR-3 で確定。ユーザー承認済み）
- 銘柄コードは編集不可。モーダル内は読み取り専用の銘柄名・コード表示のみとする
  （`UpdateHoldingRequest` が `code` を持たない設計に合わせる）
- 入力欄・検証規則（`<NumberInput>`・全角正規化・範囲検証・0以下拒否）は
  §5 冒頭の追加フォームと同一

### 5.2 削除操作の確認

- 保有銘柄の削除（§5.1 の編集ボタンと同じ行の「削除」ボタン）・
  ポートフォリオの削除（§9 の配置）は、いずれもブラウザ標準の `window.confirm()`
  による確認を経てから実行する
- 専用の確認モーダル（`<Dialog>`）は導入していない**暫定実装**である
  （T-103 FEレビュー CR-3。既存の確認UIパターンが無かったための判断。
  より丁寧な確認UIへの差し替えは今後の検討課題）

## 6. 空状態

| 状況                              | 表示                                                                 |
| :-------------------------------- | :------------------------------------------------------------------- |
| ポートフォリオを1つも持たない     | 破線枠カード「ポートフォリオがありません」＋「＋ 作成」導線          |
| ポートフォリオはあるが保有銘柄0件 | 集計は全て「0 円」/`—`。テーブルの代わりに「銘柄を追加してください」 |

## 7. 読み込み中・エラー時の表示

- 初回取得中は `<Skeleton>`（集計カード＋テーブルの高さを維持）
- 取得失敗時は `role="alert"`。「時間をおいて再読み込みしてください」

## 8. データ取得（API 要件）

集計値は**サーバー側で計算して返す**（`.claude/CLAUDE.md`「計算・判定は必ず domain へ」）。
フロントは受け取った値を表示するだけで、評価額・評価損益等をクライアントで再計算しない。
API 契約は [portfolio-api.md](../../api/portfolio-api.md)（T-083）が正。

## 9. アクセシビリティ

- 保有銘柄テーブルは `<table>`
- ポートフォリオ切替タブは `role="tablist"`/`role="tab"` または `<button>` の集合
  （`div`+`onClick` にしない）
- 追加・削除操作は `<button>`
- ポートフォリオの削除ボタンは `PortfolioTabs`（タブ列）には置かない。選択中
  ポートフォリオの**詳細表示側**（§3 の集計カードより前、保有銘柄テーブルの上部）に
  配置する（T-103 FEレビュー CR-3。タブ列は切替専用の操作に限定し、破壊的操作と
  混在させないため）

## 10. 受入基準

- ✅ 保有0件のポートフォリオで評価額合計が「0 円」と表示され、`—` にならない
- ✅ スコア平均は保有0件のとき `—`（0点と表示しない。ゼロ除算を隠さない）
- ✅ 平均利回り（評価額加重）の計算に、利回り `null` の銘柄は含まれない
- ✅ 平均利回り・取得単価利回りの末尾に対象銘柄数（`yieldEvaluableHoldingCount`）が表示される
- ✅ 各保有銘柄行のスコアに「（N/10）」が併記される（省略しない）
- ✅ 評価損益が負の行に `▼` と `--color-negative` が両方出る（色だけに依存しない）
- ✅ 現在株価が未入力の銘柄で評価額が `—` になり、`0` にならない
- ✅ ポートフォリオが10個のとき「＋ 追加」が `disabled`
- ✅ 保有銘柄が100件のとき「＋ 銘柄を追加」が `disabled`
- ✅ 保有銘柄の行クリックで `?code=` が付き、解析ダイアログが開く
- ✅ 集計値はクライアントで再計算せず、API のレスポンスをそのまま表示する
- ✅ `frontend/` に色・サイズの直値が無い（[design-tokens.md](../design-tokens.md) §6）
