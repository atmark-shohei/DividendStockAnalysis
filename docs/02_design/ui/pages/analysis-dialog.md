## 1. 概要

**1銘柄の採点結果を全指標ぶん見せる、モーダルダイアログ。**
検索一覧（`/`）・ポートフォリオ（`/portfolio`）の行クリックから開く共通部品。

**この画面がしないこと:**

- スコアの計算（すでに確定した `ScoringResponse` を表示するだけ）
- 複数銘柄の比較（F-33。別画面の役割）
- 投資判断の提示（「買い」「割安」等の評価文言を出さない。§4.3）
- ポートフォリオへの追加・保有数量の編集（`/portfolio` 側の責務）

**2つのモードを持つ**（既存の `ListPage` の「解析結果」インラインセクションを
モーダル化したもの）。

- **概要モード**（既定）: 総合スコア・レーダーチャート・10指標の比較表
- **指標詳細モード**: 1指標にドリルダウンした詳細（線グラフ／連続年数リスト／汎用）

## 2. URL・開閉

**[ADR-0014](../../../adr/0014-analysis-dialog-url-state.md) が正。** 要点だけ再掲する。

| 状態                 | URL                            |
| :------------------- | :----------------------------- |
| 閉                   | `?code=` 無し                  |
| 開（概要モード）     | `?code=<コード>`               |
| 開（指標詳細モード） | `?code=<コード>&metric=<キー>` |

- 行クリックで開く場合は常に**概要モードから始まる**（`metric` を付けない）
- `?code=X&metric=Y` への直リンクは**指標詳細から始まってよい**（共有・ブックマークの利点）
- ✕ ボタン・背景（scrim）クリック・Escape キー → `code` と `metric` の両方を外す（閉じる）
- 「← 指標一覧へ戻る」 → `metric` だけを外す（`code` は残る。ダイアログは閉じない）
- **背景クリックは「指標一覧へ戻る」の代わりにならない。** 指標詳細モードで背景を
  クリックするとダイアログごと閉じる（試作の挙動どおり）

## 5. 指標詳細モード

「← 指標一覧へ戻る」ボタン ＋ 指標名 ＋ 現在値・スコアの後、指標ごとに3種類のいずれかを表示する。

### 5.1 線グラフ（①増配率（5年CAGR）のみ。F-52）

- SVG の折れ線グラフ（Recharts。[components.md](../components.md) §7 決定）
- **年度は固定8年ではなく、その銘柄に登録されている `dividend_records` の
  全年度**（昇順）。予想（`kind = 'forecast'`）の年度は年ラベルに「（予想）」を付ける
- 縦軸グリッド線、各点の上に金額ラベル、下に年度ラベル
- グラフの下に表（年度／1株配当／前年比）。前年比は `▲ +N円` / `▼ -N円` / `－ 据置`
  （色＋glyph＋文言。色だけに依存しない。`.claude/rules/frontend.md`）
- **配当データが1年分しか無い（前年比を計算できない）場合、その行の前年比は `—`**
  （`±0円` にしない。データ欠損と「変化なし」を区別する）

### 5.2 連続年数リスト（②連続非減配年数のみ。F-53）

- 縦並びのリスト。1行＝1年度。年度・`▲`/`－`/`▼` glyph＋色・状態語
  （増配／据置／減配）・金額・前年差
- 末尾に要約行:「減配のない状態が **`consecutiveYears`年** 継続中です。」
- 対象年度は最大18年遡及（`consecutive-years-scoring.md` の定義に合わせる）
- **予想年度（`kind: 'forecast' | 'revised'`）は対象に含まない。** ①の線グラフとは
  異なり、リストには実績（`kind: 'actual'`）年度のみが並ぶ。データソースは
  スコア算出（`consecutiveYears`）と同一の実績限定系列で、要約行とリストの
  増配/減配表示が矛盾しないようにするための仕様（T-098。2026-08-22）
- 実装は `<table>`（①と統一。年度／状態／1株配当／前年差の4列）＋末尾の要約行
  （`frontend/components/ConsecutiveYearsList.tsx`）。増配／据置／減配の判定・前年差の
  算出は BE domain（`describeConsecutiveYearRows()`）で完了済みで、FE は再計算しない

### 5.3 汎用（残り8指標。③④⑤⑥⑦⑧⑨⑩）

- 計算式を等幅フォントのインセットブロックで表示
- **条件／点数の表は [評価基準タブ](./criteria-tab.md) と同じ `bands.ts` から描画する。**
  ハードコードしない・二重管理しない（`criteria-tab.md` §3 と同じ規約）
- ③のカードには、予想／実績それぞれの値・スコア・採用元を併記する
  （`payoutRatioBreakdownText` を流用）
- **③は §5.3.1 が優先する。** ③（`payoutRatio`）が選ばれたときは本節の汎用表示ではなく
  §5.3.1 の専用表示を使う（✅ 2026-09-23 追記、Y4・T-108）

### 5.3.1 ③ 予想配当性向の詳細（T-108。2026-09-23 設計・未実装）

**目的:** 「なぜこの点数になったか」を、計算式と**実際の計算に使った数値**で示す。
判定・計算はすべて BE（domain）で確定済みの値を使い、**FE は区分の判定もしない**
（[payout-ratio-scoring.md](../../logic/payout-ratio-scoring.md) §10.2）。

`AnalysisDialogBody.tsx` の指標詳細モードで `activeMetric.key === 'payoutRatio'` のときに
表示する（①②と同じく、指標ごとの分岐を1つ追加する。他の汎用指標は引き続きプレースホルダー）。

```

┌──────────────────────────────────────────────┐
│ 配当性向 = 配当金 ÷ EPS × 100                  │ ← 記号式（等幅・インセット）
└──────────────────────────────────────────────┘

```

## 6. 読み込み中・エラー時の表示

- ダイアログを開いた直後、`ScoringResponse` の取得が終わるまでは
  ヘッダー（銘柄名）だけを先に出し、本体は `<Skeleton>` にする
  （既に選択済みの銘柄名は一覧のデータから分かるため、タイトルは即座に出せる）
- 取得に失敗した場合、ダイアログ内に `role="alert"` でエラーを表示し、
  「一覧から選び直してください」等の次の行動を示す。ダイアログは閉じない
  （閉じると URL の `?code=` が残ったままエラーの手がかりが消える）

## 8. アクセシビリティ

- ダイアログは `role="dialog"` `aria-modal="true"` `aria-labelledby="<銘柄名の要素ID>"`
- **フォーカストラップ。** 開いたら最初のフォーカス可能要素（✕ボタン）へ移動し、
  Tab はダイアログ内で循環する
- Escape キーで閉じる（概要・詳細どちらのモードでも）
- 比較表の行・「← 指標一覧へ戻る」は [search-page.md](./search-page.md) §4.1 と同じ
  **stretched button パターン**（`div` + `onClick` にしない）
- 閉じたらフォーカスを元の呼び出し元（一覧の行ボタン）に戻す

## 9. 受入基準

- ✅ 一覧の行を Enter/Space または クリックで開くと、概要モードで開く（`?code=` のみ）
- ✅ 指標行を開くと `?metric=<キー>` が付き、詳細モードに切り替わる
- ✅ 「← 指標一覧へ戻る」を押すと `?metric=` だけが外れ、`?code=` は残る
- ✅ ✕ ボタン・背景クリック・Escape のいずれでも `?code=` と `?metric=` の両方が外れる
- ✅ `?code=X&metric=roeAverage` に直接アクセスすると、指標詳細モードで開く
- ✅ PBR が `null` の銘柄で「— データなし」と表示され、`0` は出ない
- ✅ 指標カスタマイズ実装後、総合スコアの下に総合点の比較不能を示す注記が表示される
- ✅ 「評価」列は比較表に存在しない（§4.3）
- ✅ 判定不能（`score: null`）の行にスコアバーが表示されず、`—` が出る
- ✅ ①の線グラフで、配当が1年分しかない年度の前年比が `—` になり `±0円` にならない
- ✅ ダイアログを開くとフォーカストラップが働き、Tab がダイアログ外に出ない
- ✅ Escape キーでダイアログが閉じ、フォーカスが呼び出し元の行ボタンに戻る
- ✅ `frontend/` に色・サイズの直値が無い（[design-tokens.md](../design-tokens.md) §6）
