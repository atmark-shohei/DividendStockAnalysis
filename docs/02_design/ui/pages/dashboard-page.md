# ダッシュボード（S-01）

> ステータス: 🟡 draft
> パス: `/` / 実装: `src/app/page.tsx`

## 目的

「今日、自分の関心銘柄がどうなっているか」を1画面で把握する。
新規の銘柄探索は S-02（スクリーナー）の役割。ここには持ち込まない。

## レイアウト

```
┌──────────────────────────────────────────────┐
│ ヘッダー                最終取得: 2026-07-26 09:00 │
├──────────────────────────────────────────────┤
│  サマリー                                       │
│  ┌──────────┬──────────┬──────────┐          │
│  │ 登録銘柄数 │ 平均利回り │ 権利確定間近 │          │
│  │   12件    │   4.21%   │    3件     │          │
│  └──────────┴──────────┴──────────┘          │
├──────────────────────────────────────────────┤
│  ウォッチリスト（利回り降順）                       │
│  ┌────┬────────┬────────┬────────┬────────┐  │
│  │コード│ 銘柄名  │  株価  │ 年間配当 │  利回り │  │
│  ├────┼────────┼────────┼────────┼────────┤  │
│  │9999│テスト商事│3,000 円│  160 円 │ 5.33% │  │
│  └────┴────────┴────────┴────────┴────────┘  │
├──────────────────────────────────────────────┤
│  権利確定日が近い銘柄                             │
├──────────────────────────────────────────────┤
│  フッター（免責文言）                              │
└──────────────────────────────────────────────┘
```

## データ取得

- Server Component で `src/lib/watchlist` → `src/lib/db` を呼ぶ
- API Route を経由しない（同一プロセス内なので不要）
- 1回のクエリで取得する。銘柄ごとに追加クエリを投げない（N+1 禁止）

## 表示ルール

| 項目         | ルール                                                         |
| ------------ | -------------------------------------------------------------- |
| 株価         | `<Money>` を使う。3桁区切り＋「円」                            |
| 年間配当     | `<Money>`。**予想値なら「（予想）」を付ける**                  |
| 利回り       | `<Yield>`。小数第2位＋`%`                                      |
| データ欠損   | `—` を表示。**0 を表示しない**                                 |
| 平均利回り   | 計算できた銘柄のみで算出し、母数を併記（`4.21%（10/12銘柄）`） |
| 最終取得時刻 | ヘッダーに常時表示。一定時間超過で警告                         |

## 状態

| 状態               | 表示                                                             |
| ------------------ | ---------------------------------------------------------------- |
| ロード中           | `<Skeleton>`。テーブルと同じ行高でレイアウトを飛ばさない         |
| ウォッチリストが空 | `<EmptyState>`「銘柄が登録されていません」＋スクリーナーへの導線 |
| データ取得失敗     | `<ErrorState>`。キャッシュがあれば古いデータ＋警告を出す         |
| 一部銘柄のみ欠損   | 該当行だけ `—`。画面全体をエラーにしない                         |

## 操作

| 操作               | 挙動                             |
| ------------------ | -------------------------------- |
| 銘柄行クリック     | S-03 銘柄詳細へ遷移              |
| 列ヘッダークリック | ソート。**URL クエリに反映**する |
| 手動更新ボタン     | 外部データ源から再取得（P1）     |

## 受入基準

- ✅ ウォッチリスト12件の表示が 1.0 秒以内
- ✅ 株価が `null` の銘柄で `—` が表示され、利回り欄も `—` になる
- ✅ 無配（0円）の銘柄で「0 円」と表示され、`—` にならない
- ✅ 予想配当を使っている銘柄に「（予想）」が付く
- ✅ ソート順が URL に反映され、リロードで維持される
- ✅ 空状態でスクリーナーへの導線が出る
