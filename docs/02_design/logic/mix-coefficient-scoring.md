# MIX係数（PER × PBR） スコアリング 仕様書（指標⑨）

> **スコア表の原典:** [scoring-requirements.md](../../01_requirements/scoring-requirements.md) の指標⑨（SSoT）
> **閾値は原典から一切変更していない。** 投資判断に直結するため、変更はユーザーの明示的な決定を要する。
> 参考資料との差分は §7 と
> [scoring-source-comparison.md](../../01_requirements/scoring-source-comparison.md) にある。

## 1. 概要

- **分類:** 割安度

割安度の指標。**旧実装には無い新規指標。**
参考資料では CN-PER が主指標で MIX係数はその代用だが、**SSoT は MIX係数を主指標としている**（§7）。

## 2. 入出力

**入力**

| 項目  | 型               | 単位 | 備考                                      |
| :---- | :--------------- | :--- | :---------------------------------------- |
| `per` | `number \| null` | 倍   | PER（会社予想）。**負（赤字）がありうる** |
| `pbr` | `number \| null` | 倍   | PBR（実績）                               |

**出力**

| 項目    | 型               | 備考                              |
| :------ | :--------------- | :-------------------------------- |
| `score` | `number \| null` | 0〜10 の整数。判定不能なら `null` |
| `value` | `number \| null` | 判定に使った算出値。表示用        |

> **金額は銭単位の整数で受け取り、途中で浮動小数点に落とさない。**
> 比率の算出でのみ小数を使い、**丸めるのは表示層の1箇所だけ**。

## 3. 計算式

$$\text{MIX係数} = \text{PER (会社予想)} \times \text{PBR (実績)}$$

## 4. スコア判定

区分の解釈は **「下限以上、上限未満」**（[§0.1](../../01_requirements/scoring-requirements.md)）。
最上位行のみ「下限以上」、最下位行のみ「上限以下」。

| 下限   | 上限   | 点数 |
| :----- | :----- | :--- |
| 0倍    | 10倍   | 10   |
| 10倍   | 12倍   | 9    |
| 12倍   | 15倍   | 8    |
| 15倍   | 18倍   | 7    |
| 18倍   | 22.5倍 | 6    |
| 22.5倍 | 25倍   | 5    |
| 25倍   | 27倍   | 4    |
| 27倍   | 30倍   | 3    |
| 30倍   | 33倍   | 2    |
| 33倍   | 40倍   | 1    |
| 40倍   | 以上   | 0    |

## 5. 例外処理

| 状況                     | スコア   | 画面表示                        |
| :----------------------- | :------- | :------------------------------ |
| PER または PBR が `null` | `null`   | `—`（データなし）               |
| **PER が負（赤字）**     | **0点**  | 算出値 / 0点（§0.3）            |
| PBR が負（債務超過）     | **0点**  | 算出値 / 0点（§0.3 と同じ理由） |
| MIX係数が 0              | **10点** | `0.00倍` / 10点                 |

**`null`（判定不能）と 0点は別物。** 画面には `0` ではなく `—` を出す。

> 総合点の集計時のみ `null` を 0点として合算する（[§0.5](../../01_requirements/scoring-requirements.md)。
> 分母は常に 100点）。総合点の隣に有効指標数を併記すること。

## 6. 受入基準

実装時にこの4系統をすべてテストすること。1つでも欠けたら未完了とする。

### 6.1 境界値ちょうど

- [ ] `10.0倍` → **9点**（10点ではない）
- [ ] `9.999...倍` → 10点
- [ ] `40.0倍` → **0点**
- [ ] `39.999...倍` → 1点
- [ ] `22.5倍` → **5点**

### 6.2 負の値

**PER が負なら 0点**（§0.3）。表の「0倍〜10倍 → 10点」は正の MIX係数にのみ適用する。
これを守らないと**赤字企業が満点**になる。③ と構造的に同一の欠陥。

### 6.3 無配・0

MIX係数 0 は最上位区分に該当し 10点。PER か PBR が 0 のときに起きるが、現実にはほぼ異常値。

### 6.4 データ欠損

`null` を返す条件: PER または PBR が `null`。

- [ ] 上記の各条件で `null` が返る（**0 が返らない**）
- [ ] 画面表示が `—` になる（`0` や `0.00%` にならない）

## 7. 参考資料との差分

参考資料 `high_dividend_10_indicators_scoring.md`（YouTube「高配当ラボ」由来）の
**⑨ CN-PER（主）＋ ⑨′ MIX係数（代用）** に相当する。

10点〜7点（10倍以下〜15〜18倍）まで一致。

| 項目       | 本仕様（SSoT） | 参考資料                    |
| :--------- | :------------- | :-------------------------- |
| **主指標** | MIX係数        | **CN-PER**（MIX係数は代用） |
| 6点の区間  | 18〜22.5倍     | **18〜20倍**                |
| 5点の区間  | 22.5〜25倍     | **20〜22.5倍**              |
| 4点の区間  | 25〜27倍       | **22.5〜25倍**              |
| 3点の区間  | 27〜30倍       | **25〜27倍**                |
| 2点の区間  | 30〜33倍       | **27〜30倍**                |
| 1点の区間  | 33〜40倍       | **行なし**                  |
| 0点        | 40倍以上       | **30倍以上**                |

**影響:**

**相違が2層ある。**

1. **主指標が違う。** 参考資料は CN-PER（ネットキャッシュを差し引いた実質 PER）が本命で、
   MIX係数はネットキャッシュが負の銘柄への代用。SSoT に CN-PER は**存在しない**。
2. **MIX係数の表も 18倍以上で全行ずれる。** かつ参考資料は 30倍以上を一律 0点とし、
   SSoT の 1点行が無い。例: MIX 28倍は SSoT で 3点、参考資料で 2点。

CN-PER を採用すると ⑥ のネットキャッシュを再利用でき、指標間の一貫性が上がる。

> 🔴 **未決。** どちらを採用するかは決まっていない。本仕様は SSoT のまま据え置いている。
> 判断は [scoring-source-comparison.md](../../01_requirements/scoring-source-comparison.md) で一括して行う。
