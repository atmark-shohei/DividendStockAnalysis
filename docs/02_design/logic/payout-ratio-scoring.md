# 予想配当性向 スコアリング 仕様書（指標③）

> **スコア表の原典:** [scoring-requirements.md](../../01_requirements/scoring-requirements.md) の指標③（SSoT）
> **閾値は原典から一切変更していない。** 投資判断に直結するため、変更はユーザーの明示的な決定を要する。
> 参考資料との差分は §7 と
> [scoring-source-comparison.md](../../01_requirements/scoring-source-comparison.md) にある。

## 1. 概要

- **分類:** 増配余力

今期予想の当期純利益（EPS）に対する配当金の割合。**低いほど増配余力が大きい**と判断し
高得点になる。

## 2. 入出力

**入力**

| 項目               | 型               | 単位       | 備考                                        |
| :----------------- | :--------------- | :--------- | :------------------------------------------ |
| `forecastDividend` | `number \| null` | 銭（整数） | 今期予想の1株配当                           |
| `forecastEps`      | `number \| null` | 銭（整数） | 今期予想の1株利益。**負（赤字）がありうる** |

**出力**

| 項目    | 型               | 備考                              |
| :------ | :--------------- | :-------------------------------- |
| `score` | `number \| null` | 0〜10 の整数。判定不能なら `null` |
| `value` | `number \| null` | 判定に使った算出値。表示用        |

> **金額は銭単位の整数で受け取り、途中で浮動小数点に落とさない。**
> 比率の算出でのみ小数を使い、**丸めるのは表示層の1箇所だけ**。

## 3. 計算式

$$\text{予想配当性向 (\%)} = \left( \frac{\text{予想1株配当}}{\text{予想EPS}} \right) \times 100$$
「配当」ブロックの最新予想と「業績」ブロックの最新予想 EPS から求める。
CSV に `配当性向` 列があればそれを優先してよい（`scoring-requirements.md` §2.4）。

## 4. スコア判定

区分の解釈は **「下限以上、上限未満」**（[§0.1](../../01_requirements/scoring-requirements.md)）。
最上位行のみ「下限以上」、最下位行のみ「上限以下」。

| 下限 | 上限 | 点数 |
| :--- | :--- | :--- |
| 0%   | 25%  | 10   |
| 25%  | 30%  | 9    |
| 30%  | 35%  | 8    |
| 35%  | 40%  | 7    |
| 40%  | 45%  | 6    |
| 45%  | 50%  | 5    |
| 50%  | 55%  | 4    |
| 55%  | 60%  | 3    |
| 60%  | 65%  | 2    |
| 65%  | 70%  | 1    |
| 70%  | 以上 | 0    |

## 5. 例外処理

| 状況                               | スコア  | 画面表示              |
| :--------------------------------- | :------ | :-------------------- |
| EPS が `null`                      | `null`  | `—`（データなし）     |
| 配当が `null`                      | `null`  | `—`（データなし）     |
| EPS が 0                           | `null`  | `—`（ゼロ除算）       |
| **EPS が負（赤字）**               | **0点** | 算出値 / 0点（§0.3）  |
| **無配（配当 0 かつ配当性向 0%）** | **0点** | `0.00%` / 0点（§0.4） |

**`null`（判定不能）と 0点は別物。** 画面には `0` ではなく `—` を出す。

> 総合点の集計時のみ `null` を 0点として合算する（[§0.5](../../01_requirements/scoring-requirements.md)。
> 分母は常に 100点）。総合点の隣に有効指標数を併記すること。

## 6. 受入基準

実装時にこの4系統をすべてテストすること。1つでも欠けたら未完了とする。

### 6.1 境界値ちょうど

- [ ] `25.0%` → **9点**（10点ではない）
- [ ] `24.999...%` → 10点
- [ ] `70.0%` → **0点**
- [ ] `69.999...%` → 1点
- [ ] `0.0%` かつ配当 > 0 → 10点
- [ ] `0.0%` かつ配当 == 0（無配）→ **0点**

### 6.2 負の値

**EPS が負なら 0点**（§0.3）。表の「0%〜25% → 10点」は正の配当性向にのみ適用する。
これを守らないと**赤字企業が満点**になる。

### 6.3 無配・0

**無配（配当額 0）は 0点**（§0.4）。配当性向 0% は数値上は最上位区分だが、
高配当銘柄を探す目的に反するため 0点とする。配当額が 0 かどうかで分岐すること。

### 6.4 データ欠損

`null` を返す条件: EPS または配当が `null`、あるいは EPS が 0。

- [ ] 上記の各条件で `null` が返る（**0 が返らない**）
- [ ] 画面表示が `—` になる（`0` や `0.00%` にならない）

## 7. 参考資料との差分

参考資料 `high_dividend_10_indicators_scoring.md`（YouTube「高配当ラボ」由来）の
**③（予想配当性向）** に相当する。

70%以上 → 0点 まで、60% 未満の全行が一致。

| 項目     | 本仕様（SSoT） | 参考資料              |
| :------- | :------------- | :-------------------- |
| 60%〜65% | 2点            | 2点（60〜70% で一括） |
| 65%〜70% | **1点**        | **2点**（同上）       |

**影響:**

配当性向 65〜70% の銘柄で 1点差が出る。相違は1行のみで影響は小さい。

> 🔴 **未決。** どちらを採用するかは決まっていない。本仕様は SSoT のまま据え置いている。
> 判断は [scoring-source-comparison.md](../../01_requirements/scoring-source-comparison.md) で一括して行う。

## 8. 既存実装との対応

旧実装（[reference/legacy-web/](../../../reference/legacy-web/README.md)）は**再利用しない**（T-008）。
挙動の記録としてのみ参照する。
