# 配当維持可能年数 スコアリング 仕様書（指標⑥）

> **スコア表の原典:** [scoring-requirements.md](../../01_requirements/scoring-requirements.md) の指標⑥（SSoT）
> **出典の相違と決定:** [scoring-source-comparison.md](../../01_requirements/scoring-source-comparison.md)
> 参考資料との差分と、それに対する決定は §7 にある。

## 1. 概要

- **分類:** 増配余力（財務健全性）

手元のネットキャッシュだけで現行の配当総額を何年維持できるか。
**旧実装には無い新規指標。**

## 2. 入出力

**入力**

| 項目                    | 型               | 単位       | 備考             |
| :---------------------- | :--------------- | :--------- | :--------------- |
| `currentAssets`         | `number \| null` | 銭（整数） | 流動資産         |
| `investmentSecurities`  | `number \| null` | 銭（整数） | 投資有価証券     |
| `totalLiabilities`      | `number \| null` | 銭（整数） | 負債総額         |
| `previousDividendTotal` | `number \| null` | 銭（整数） | 前期末の配当総額 |

**出力**

| 項目    | 型               | 備考                              |
| :------ | :--------------- | :-------------------------------- |
| `score` | `number \| null` | 0〜10 の整数。判定不能なら `null` |
| `value` | `number \| null` | 判定に使った算出値。表示用        |

> **金額は銭単位の整数で受け取り、途中で浮動小数点に落とさない。**
> 比率の算出でのみ小数を使い、**丸めるのは表示層の1箇所だけ**。

## 3. 計算式

$$\text{配当維持可能年数} = \frac{\text{ネットキャッシュ}}{\text{前期末の配当総額}}$$
ネットキャッシュ $= (\text{流動資産} + \text{投資有価証券} \times 0.7) - \text{負債総額}$

> 一般的な「現金同等物 − 有利子負債」ではなく、投資有価証券を 0.7 掛けで算入する
> **独自定義**。売却時の税を考慮したもので、意図的なものとして扱う。
> 0.7 を掛ける前に整数へ丸めないこと（銭単位のまま計算し、最後に丸める）。

## 4. スコア判定

区分の解釈は **「下限以上、上限未満」**（[§0.1](../../01_requirements/scoring-requirements.md)）。
最上位行のみ「下限以上」、最下位行のみ「上限以下」。

| 下限 | 上限    | 点数 |
| :--- | :------ | :--- |
| 30年 | 以上    | 10   |
| 20年 | 30年    | 9    |
| 10年 | 20年    | 8    |
| 8年  | 10年    | 7    |
| 6年  | 8年     | 6    |
| 5年  | 6年     | 5    |
| 4年  | 5年     | 4    |
| 3年  | 4年     | 3    |
| 2年  | 3年     | 2    |
| 0年  | 2年     | 1    |
| —    | 0年未満 | 0    |

> ⚠️ **2026-07-27 に変更。** 原典の `1〜2年 → 1点` / `0〜1年 → 0点` を
> **`0〜2年 → 1点` に統合**し、**0点はネットキャッシュが負のときだけ**にした（§7）。

## 5. 例外処理

| 状況                                 | スコア  | 画面表示          |
| :----------------------------------- | :------ | :---------------- |
| 入力のいずれかが `null`              | `null`  | `—`（データなし） |
| 前期末の配当総額が 0（無配）         | `null`  | `—`（ゼロ除算）   |
| **ネットキャッシュが負（債務超過）** | **0点** | 算出値 / 0点      |
| ネットキャッシュが 0                 | **1点** | `0年` / 1点       |

**`null`（判定不能）と 0点は別物。** 画面には `0` ではなく `—` を出す。

> 総合点の集計時のみ `null` を 0点として合算する（[§0.5](../../01_requirements/scoring-requirements.md)。
> 分母は常に 100点）。総合点の隣に有効指標数を併記すること。

## 6. 受入基準

実装時にこの4系統をすべてテストすること。1つでも欠けたら未完了とする。

### 6.1 境界値ちょうど

- [ ] `30年` → **10点**
- [ ] `29.999...年` → 9点
- [ ] `2年` → **2点**
- [ ] `1.999...年` → **1点**
- [ ] `0年` → **1点**（0点ではない）
- [ ] `-0.001年`（債務超過）→ **0点**

### 6.2 負の値

**ネットキャッシュが負なら 0点。** 0点の意味を「債務超過」だけに限定する（2026-07-27 決定）。
この指標では 0点が財務上の危険信号を意味するので、正のキャッシュと混ぜない。

### 6.3 無配・0

前期末配当総額が 0（無配）は**ゼロ除算で `null`**。0点ではない。
ネットキャッシュがちょうど 0 は **1点**（負ではないため）。

### 6.4 データ欠損

`null` を返す条件: 入力に `null` がある、または前期末の配当総額が 0。

- [ ] 上記の各条件で `null` が返る（**0 が返らない**）
- [ ] 画面表示が `—` になる（`0` や `0.00%` にならない）

## 7. 参考資料との差分と決定

参考資料 `high_dividend_10_indicators_scoring.md`（YouTube「高配当ラボ」由来）の
**⑥（配当維持可能年数）** に相当する。

10点〜2点（30年以上〜2年）まで**完全一致**。計算式・ネットキャッシュの定義も一致。

| 項目     | 原典（SSoT）        | 参考資料            |
| :------- | :------------------ | :------------------ |
| 1年〜2年 | 1点（原典）         | **行なし（穴）**    |
| 0年〜1年 | 0点（原典）         | 1点                 |
| 0年未満  | 表外（§0.3 で 0点） | 0点（表に明記あり） |

**影響:**

参考資料の側に穴がある（1〜2年がどの行にも該当しない）一方、
**「0年未満 → 0点」が表に明記されており、§0.3（負は 0点）の判断を裏付けている。**

### 決定（2026-07-27）

✅ **`0〜2年 → 1点` に統合し、0点は債務超過（ネットキャッシュが負）のときだけとした。**
上のスコア表は変更済み。

原典のままだと、配当3ヶ月分の現金がある会社と債務超過の会社がどちらも 0点になり、
**実質的に異なる財務状態を区別できない。** 参考資料の「0年〜1年 → 1点 /
0年未満 → 0点」という構造がこの問題を解いているので、穴（1〜2年）を埋める形で採った。

この指標の 0点は「債務超過」という明確な意味を持つ。実装時にコメントで明示すること。

## 8. 既存実装との対応

**旧実装には無い。** 前例のない完全な新規実装になる。

旧実装（[reference/legacy-web/](../../../reference/legacy-web/README.md)）は**再利用しない**（T-008）。
挙動の記録としてのみ参照する。
