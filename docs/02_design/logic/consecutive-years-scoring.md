# 連続非減配年数 スコアリング 仕様書（指標②）

> **スコア表の原典:** [scoring-requirements.md](../../01_requirements/scoring-requirements.md) の指標②（SSoT）
> **出典の相違と決定:** [scoring-source-comparison.md](../../01_requirements/scoring-source-comparison.md)
> 参考資料との差分と、それに対する決定は §7 にある。

## 1. 概要

- **分類:** 増配の安定性

直近から過去18年前まで遡り、前年比で減配していない連続年数。
**「増配」ではなく「非減配」**（横ばいを含む）である点に注意。

## 2. 入出力

**入力**

| 項目              | 型                   | 単位       | 備考                           |
| :---------------- | :------------------- | :--------- | :----------------------------- |
| `dividendHistory` | `(number \| null)[]` | 銭（整数） | 年度降順の配当履歴。最大18年分 |

**出力**

| 項目    | 型               | 備考                              |
| :------ | :--------------- | :-------------------------------- |
| `score` | `number \| null` | 0〜10 の整数。判定不能なら `null` |
| `value` | `number \| null` | 判定に使った算出値。表示用        |

> **金額は銭単位の整数で受け取り、途中で浮動小数点に落とさない。**
> 比率の算出でのみ小数を使い、**丸めるのは表示層の1箇所だけ**。

## 3. 計算ロジック

直近年から過去へ順に走査し、`当年 < 前年` となった時点で打ち切る。
`当年 == 前年`（横ばい）は**継続とみなす**。

## 4. スコア判定

区分の解釈は **「下限以上、上限未満」**（[§0.1](../../01_requirements/scoring-requirements.md)）。
最上位行のみ「下限以上」、最下位行のみ「上限以下」。

| 下限 | 上限 | 点数 |
| :--- | :--- | :--- |
| 17年 | 以上 | 10   |
| 10年 | 16年 | 5    |
| 5年  | 9年  | 3    |
| 0年  | 4年  | 0    |

## 5. 例外処理

| 状況                           | スコア   | 画面表示                    |
| :----------------------------- | :------- | :-------------------------- |
| 配当履歴が空                   | `null`   | `—`（データなし）           |
| 履歴の途中に `null` がある     | `null`   | `—`（連続性を判定できない） |
| 全期間で非減配（18年分すべて） | **10点** | `18年` / 10点               |
| 直近が減配                     | **0点**  | `0年` / 0点                 |

**`null`（判定不能）と 0点は別物。** 画面には `0` ではなく `—` を出す。

> 総合点の集計時のみ `null` を 0点として合算する（[§0.5](../../01_requirements/scoring-requirements.md)。
> 分母は常に 100点）。総合点の隣に有効指標数を併記すること。

## 6. 受入基準

実装時にこの4系統をすべてテストすること。1つでも欠けたら未完了とする。

### 6.1 境界値ちょうど

- [ ] `17年` → **10点**
- [ ] `16年` → 5点
- [ ] `10年` → **5点**
- [ ] `9年` → 3点
- [ ] `5年` → **3点**
- [ ] `4年` → 0点

### 6.2 負の値

年数は 0 以上の整数なので負にならない。**該当なし。**

### 6.3 無配・0

0年（直近が減配）は最下段に該当し **0点**。`null` ではない。

### 6.4 データ欠損

`null` を返す条件: 配当履歴が空、または連続性の判定範囲内に `null` が含まれる。

- [ ] 上記の各条件で `null` が返る（**0 が返らない**）
- [ ] 画面表示が `—` になる（`0` や `0.00%` にならない）

## 7. 参考資料との差分と決定

参考資料 `high_dividend_10_indicators_scoring.md`（YouTube「高配当ラボ」由来）の
**①（連続増配年数）** に相当する。

最上位（17期以上 → 10点）のみ一致。

| 項目       | 原典（SSoT）                       | 参考資料                       |
| :--------- | :--------------------------------- | :----------------------------- |
| 定義       | 連続**非減配**年数（横ばいを含む） | 連続**増配**年数（増加が必要） |
| 14年〜16年 | 5点（10〜16年の一部）              | 7点                            |
| 10年〜13年 | 5点（同上）                        | 6点                            |
| 5年〜9年   | 3点                                | 5点                            |
| 3年〜4年   | 0点（0〜4年）                      | 2点                            |
| 3年未満    | 0点                                | 0点                            |

**影響:**

**10指標で最大の相違。定義そのものが違う。** 横ばい配当を続ける銘柄は、
SSoT では年数に算入され、参考資料では 0年になる。同じ銘柄で年数自体が変わるため、
閾値を揃えても結果は一致しない。

### 決定（2026-07-27）

✅ **非減配のまま（正典据え置き）。** 理由は3つ。

1. 旧実装も非減配で判定しており、過去の分析結果と連続性が保てる
2. 日本の高配当株はコロナ等で配当を据え置いた銘柄が多く、増配で数えるとそこで
   打ち切られて 0年になる。**減配耐性**を見る指標としては非減配が適切
3. 段階の粗さ（16年5点 → 17年10点）は認識しているが、閾値変更は行わない

> 参考資料は「高配当・増配株投資」の枠組みなので増配で数えるのが本来の意図だが、
> 本プロジェクトが見たいのは減配耐性であり、目的が異なる。

## 8.5 実装で確定させた曖昧点（2026-07-28）

実装時に §1 と §5 の記述だけでは決まらない点が2つあり、次のように確定させた。
**仕様の変更ではなく、記述の穴を埋めたもの。**

### 8.5.1 「18年前まで遡る」には19年分の値が要る

§5 は「全期間で非減配（18年分すべて）→ 18年」としているが、**n 年ぶんの
非減配を判定するには n+1 個の値が要る**（当年と1年前の比較で1年ぶん）。
18年分しか見ないと最大 17年にしかならず、この行に到達できない。

✅ **当年を含めて19年分を比較対象にする**（`CONSECUTIVE_LOOKBACK_YEARS = 18`、
実装は `slice(0, 19)`）。これで「直近が減配 → 0年」（§5）と
「全期間で非減配 → 18年」（§5）の両方が同時に成立する。

### 8.5.2 「連続性の判定範囲内の `null`」の範囲

§5 は「履歴の途中に `null` がある → `null`」、§6.4 は「**連続性の判定範囲内**に
`null` が含まれる」としており、両者の範囲が違って読める。

✅ **走査が到達した範囲だけを「判定範囲」とする。** 直近から遡る途中で `null` に
当たったら判定不能。**減配で打ち切られた後ろにある `null` は結果に影響しない**
（そこは判定に使っていないため）。走査を打ち切り時点で止めれば自然に満たされる。
