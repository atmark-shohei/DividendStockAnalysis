# 増配率（配当5年CAGR） スコアリング 仕様書（指標①）

> **スコア表の原典:** [scoring-requirements.md](../../01_requirements/scoring-requirements.md) の指標①（SSoT）
> **閾値は原典から一切変更していない。** 投資判断に直結するため、変更はユーザーの明示的な決定を要する。
> 参考資料との差分は §7 と
> [scoring-source-comparison.md](../../01_requirements/scoring-source-comparison.md) にある。

## 1. 概要

- **分類:** 増配の安定性

直近5年間の配当金の年平均成長率（CAGR）。連続年数が長くても増配幅が小さい銘柄を
見分けるための指標。

## 2. 入出力

**入力**

| 項目                   | 型               | 単位       | 備考                          |
| :--------------------- | :--------------- | :--------- | :---------------------------- |
| `dividendLastYear`     | `number \| null` | 銭（整数） | 昨年の配当金。分割調整後の値  |
| `dividendFiveYearsAgo` | `number \| null` | 銭（整数） | 5年前の配当金。分割調整後の値 |

**出力**

| 項目    | 型               | 備考                              |
| :------ | :--------------- | :-------------------------------- |
| `score` | `number \| null` | 0〜10 の整数。判定不能なら `null` |
| `value` | `number \| null` | 判定に使った算出値。表示用        |

> **金額は銭単位の整数で受け取り、途中で浮動小数点に落とさない。**
> 比率の算出でのみ小数を使い、**丸めるのは表示層の1箇所だけ**。

## 3. 計算式

$$\text{CAGR} = \left( \frac{\text{昨年の配当金}}{\text{5年前の配当金}} \right)^{\frac{1}{5}} - 1$$
株式分割の影響を排除するため、**「分割調整」列の値**を使う（`scoring-requirements.md` §2.2）。
生の配当額を使うと分割時に増配率が壊れる。

## 4. スコア判定

区分の解釈は **「下限以上、上限未満」**（[§0.1](../../01_requirements/scoring-requirements.md)）。
最上位行のみ「下限以上」、最下位行のみ「上限以下」。

| 下限 | 上限   | 点数 |
| :--- | :----- | :--- |
| 30%  | 以上   | 10   |
| 20%  | 30%    | 9    |
| 15%  | 20%    | 8    |
| 12%  | 15%    | 7    |
| 10%  | 12%    | 6    |
| 8%   | 10%    | 5    |
| 5%   | 8%     | 4    |
| 3%   | 5%     | 3    |
| 2%   | 3%     | 2    |
| 0%   | 2%     | 1    |
| —    | 0%以下 | 0    |

## 5. 例外処理

| 状況                             | スコア  | 画面表示                      |
| :------------------------------- | :------ | :---------------------------- |
| 5年前の配当金が `null`           | `null`  | `—`（データなし）             |
| 5年前の配当金が 0（無配）        | `null`  | `—`（ゼロ除算のため算出不能） |
| 昨年の配当金が `null`            | `null`  | `—`（データなし）             |
| 昨年の配当金が 0（減配して無配） | **0点** | `-100.00%` / 0点              |
| CAGR が 0% 以下（減配）          | **0点** | 算出値 / 0点                  |

**`null`（判定不能）と 0点は別物。** 画面には `0` ではなく `—` を出す。

> 総合点の集計時のみ `null` を 0点として合算する（[§0.5](../../01_requirements/scoring-requirements.md)。
> 分母は常に 100点）。総合点の隣に有効指標数を併記すること。

## 6. 受入基準

実装時にこの4系統をすべてテストすること。1つでも欠けたら未完了とする。

### 6.1 境界値ちょうど

- [ ] `20.0%` → **9点**（10点ではない）
- [ ] `19.999...%` → 8点
- [ ] `30.0%` → 10点
- [ ] `0.0%` → **0点**（1点ではない。0%以下の行に該当）
- [ ] `0.001%` → 1点

### 6.2 負の値

減配（CAGR が負）は最下段「0%以下 → 0点」に該当する。表に明示があるので §0.3 の対象外。

### 6.3 無配・0

5年前が 0 のときは**無配ではなくゼロ除算**として `null`。昨年が 0 のときは CAGR = -100% で **0点**。

### 6.4 データ欠損

`null` を返す条件: いずれかの入力が `null`、または5年前の配当金が 0。

- [ ] 上記の各条件で `null` が返る（**0 が返らない**）
- [ ] 画面表示が `—` になる（`0` や `0.00%` にならない）

## 7. 参考資料との差分

参考資料 `high_dividend_10_indicators_scoring.md`（YouTube「高配当ラボ」由来）の
**②（5年増配率）** に相当する。

上位8行（30%以上〜3%）は**完全一致**。

| 項目   | 本仕様（SSoT） | 参考資料                       |
| :----- | :------------- | :----------------------------- |
| 2%〜3% | 2点            | **行なし**（3%未満は一律 0点） |
| 0%〜2% | 1点            | **行なし**（同上）             |
| 0%以下 | 0点            | 3%未満 → 0点                   |

**影響:**

**§0.2 の判断根拠が揺らぐ。** 「0%〜2% → 1点」は転記ミスの訂正として §0.2 で確定させたが、
参考資料にはそもそも 1点・2点の行が存在せず「3%未満 → 0点」で終わっている。
増配率 1% の銘柄が SSoT では 1点、参考資料では 0点になる。

> 🔴 **未決。** どちらを採用するかは決まっていない。本仕様は SSoT のまま据え置いている。
> 判断は [scoring-source-comparison.md](../../01_requirements/scoring-source-comparison.md) で一括して行う。

## 8. 既存実装との対応

`getDividendCagrScore()` として実装あり。`>= 20 → 9点`、`> 0 → 1点` の形で穴が無かったことが §0.1 / §0.2 の裏付けになっている。

旧実装（[reference/legacy-web/](../../../reference/legacy-web/README.md)）は**再利用しない**（T-008）。
挙動の記録としてのみ参照する。
