# ROE の5年平均 スコアリング 仕様書（指標⑤）

> **スコア表の原典:** [scoring-requirements.md](../../01_requirements/scoring-requirements.md) の指標⑤（SSoT）
> **出典の相違と決定:** [scoring-source-comparison.md](../../01_requirements/scoring-source-comparison.md)
> 参考資料との差分と、それに対する決定は §7 にある。

## 1. 概要

- **分類:** 増配余力

自己資本利益率の直近5年単純平均。配当原資と BPS の蓄積速度を測る。

## 2. 入出力

**入力**

| 項目         | 型                   | 単位 | 備考                      |
| :----------- | :------------------- | :--- | :------------------------ |
| `roeHistory` | `(number \| null)[]` | %    | 年度降順の ROE。直近5年分 |

**出力**

| 項目    | 型               | 備考                              |
| :------ | :--------------- | :-------------------------------- |
| `score` | `number \| null` | 0〜10 の整数。判定不能なら `null` |
| `value` | `number \| null` | 判定に使った算出値。表示用        |

> **金額は銭単位の整数で受け取り、途中で浮動小数点に落とさない。**
> 比率の算出でのみ小数を使い、**丸めるのは表示層の1箇所だけ**。

## 3. 計算ロジック

直近5年の**単純平均**。`scoring-requirements.md` §2.4 のとおり「業績」ブロックの `ROE` 列から取る。

### 3.1. ROE の定義は「期末自己資本基準」（2026-08-10 明文化）

```
ROE(%) = 純利益 ÷ 期末自己資本 × 100
```

**分母は期首期末平均ではなく期末。** 原典は分母を明示していなかったが、実装が入力に
使っている IRバンクの業績.ROE 列が期末基準であることを実測で確定させたため、
**そちらに合わせて明文化する**（[edinet-history-import.md §2.8](./edinet-history-import.md)）。

> **なぜ明文化が要るか。** 教科書的な ROE は期首期末平均を使い、有価証券報告書の
> 「自己資本利益率」もそちらである。**同じ会社・同じ年度で最大 1.35pp 違う**
> （7203 の 2024年3月期: 期末 14.45% / 平均 15.8%）。定義を書かないまま出所を増やすと、
> 銘柄によって違う基準の値が混ざり、**⑤ の点数が出所で変わる**。
>
> どちらが「正しい」かではなく、**5年窓の中で1つに揃っていること**が要件。
> 期末基準を採るのは、既存の入力（IRバンク）がそうであり、切り替えると
> 登録済み銘柄の点数がすべて動くため。

`自己資本` は純資産ではない。純資産には非支配株主持分・新株予約権が含まれ、
これを分母にすると実測で最大 1.30pp ずれる（同 §2.8 の比較）。株主資本も違う
（8306 で 3.08pp ずれた）。

### 3.2. 入力（年度ごとの ROE）の取得

`roeHistory` は2つの出所から埋まる。**どちらも期末自己資本基準**なので混在してよい。

| 優先 | 出所                  | 取り方                                          | 期数       |
| :--- | :-------------------- | :---------------------------------------------- | :--------- |
| 1    | IRバンク 業績.ROE     | 公表列をそのまま                                | 実績4〜5期 |
| 2    | EDINET 有価証券報告書 | **純利益 ÷ 自己資本で自算**（公表列は読まない） | 実績5〜6期 |

- IRバンク単独では **業績ブロックに予想行が入る銘柄（7203・1301）で実績が4期しか無く、
  ⑤ が `—` になる**（`irbank-json-import.md` §6.2）。EDINET がこの穴を埋める
- **EDINET の公表 ROE 列は使わない。** 期首期末平均基準で §3.1 と定義が違う。
  自算値は IRバンクの公表値と **0.01pp 以内で一致**することを3銘柄12年度で確認済み
  （[edinet-history-import.md §2.8](./edinet-history-import.md)）
- 要素IDの解決・単位検証・符号ガードは同書 §4.1.1 / §4.2 / §7.6 が正。本書は重複させない
- **自己資本 ≤ 0（債務超過）の年度は `null`**（判定不能）。赤字 ÷ 負の自己資本は
  正の ROE に化け、§5 の「平均が負なら 0点」を素通りして**高得点になる**

## 4. スコア判定

区分の解釈は **「下限以上、上限未満」**（[§0.1](../../01_requirements/scoring-requirements.md)）。
最上位行のみ「下限以上」、最下位行のみ「上限以下」。

| 下限 | 上限 | 点数 |
| :--- | :--- | :--- |
| 15%  | 以上 | 10   |
| 12%  | 15%  | 9    |
| 10%  | 12%  | 8    |
| 8%   | 10%  | 7    |
| 7%   | 8%   | 6    |
| 6%   | 7%   | 5    |
| 5%   | 6%   | 4    |
| 4%   | 5%   | 3    |
| 3%   | 4%   | 2    |
| 2%   | 3%   | 1    |
| 0%   | 2%   | 0    |

## 5. 例外処理

| 状況                      | スコア  | 画面表示             |
| :------------------------ | :------ | :------------------- |
| ROE 履歴が5年分に満たない | `null`  | `—`（データ不足）    |
| 5年のうち `null` がある   | `null`  | `—`                  |
| **平均 ROE が負**         | **0点** | 算出値 / 0点（§0.3） |
| 平均 ROE が 0%            | **0点** | `0.00%` / 0点        |

**`null`（判定不能）と 0点は別物。** 画面には `0` ではなく `—` を出す。

> 総合点の集計時のみ `null` を 0点として合算する（[§0.5](../../01_requirements/scoring-requirements.md)。
> 分母は常に 100点）。総合点の隣に有効指標数を併記すること。

## 6. 受入基準

実装時にこの4系統をすべてテストすること。1つでも欠けたら未完了とする。

### 6.1 境界値ちょうど

- [ ] `15.0%` → **10点**
- [ ] `14.999...%` → 9点
- [ ] `2.0%` → **1点**
- [ ] `1.999...%` → 0点
- [ ] `0.0%` → **0点**

### 6.2 負の値

**平均 ROE が負なら 0点**（§0.3）。表の最下段は「0%〜2%」で、負の範囲は表外だった。

### 6.3 無配・0

ROE 0% は最下段「0%〜2% → 0点」に該当。無配とは無関係な指標なので**無配の分岐は無い**。

### 6.4 データ欠損

`null` を返す条件: 5年分の ROE が揃わない、または `null` を含む。

- [ ] 上記の各条件で `null` が返る（**0 が返らない**）
- [ ] 画面表示が `—` になる（`0` や `0.00%` にならない）

[edinet-history-import.md §7.6](./edinet-history-import.md) が正。**ここには重複させない。**

## 7. 参考資料との差分と決定

参考資料 `high_dividend_10_indicators_scoring.md`（YouTube「高配当ラボ」由来）の
**⑤（ROE 5年平均/中央値）** に相当する。

10点〜3点（15%以上〜4%）まで**完全一致**。

| 項目     | 原典（SSoT）    | 参考資料                              |
| :------- | :-------------- | :------------------------------------ |
| 3%〜4%   | 2点             | **行なし**（4%未満は一律 0点）        |
| 2%〜3%   | 1点             | **行なし**（同上）                    |
| 0%〜2%   | 0点             | 4%未満 → 0点                          |
| 算出方法 | 5年**平均**のみ | 5年平均。変動が大きい銘柄は**中央値** |

**影響:**

① と同じ構造の相違（下限側の刻みの有無）。ROE 3.5% の銘柄が SSoT では 2点、参考資料では 0点。

### 決定（2026-07-27）

✅ **正典据え置き。** 参考資料の「4%未満 → 0点」は採らない。① と同じ判断。

> 参考資料は「変動が大きい銘柄は中央値」としているが、**何をもって「変動が大きい」と
> するかの基準が示されておらず実装に落とせない**ため、この規定は採用しない。
> 常に5年単純平均とする。
