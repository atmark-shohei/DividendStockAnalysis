# 売上高の5年 CAGR スコアリング 仕様書（指標⑦）

> **スコア表の原典:** [scoring-requirements.md](../../01_requirements/scoring-requirements.md) の指標⑦（SSoT）
> **閾値は原典から一切変更していない。** 投資判断に直結するため、変更はユーザーの明示的な決定を要する。
> 参考資料との差分は §7 と
> [scoring-source-comparison.md](../../01_requirements/scoring-source-comparison.md) にある。

## 1. 概要

- **分類:** 収益力

売上高の年平均成長率。自社株買いやコスト削減による EPS 成長には限界があるため、
持続的な増配の最終的な裏付けになる。

## 2. 入出力

**入力**

| 項目                  | 型               | 単位       | 備考          |
| :-------------------- | :--------------- | :--------- | :------------ |
| `revenueCurrent`      | `number \| null` | 銭（整数） | 現在の売上高  |
| `revenueFiveYearsAgo` | `number \| null` | 銭（整数） | 5年前の売上高 |

**出力**

| 項目    | 型               | 備考                              |
| :------ | :--------------- | :-------------------------------- |
| `score` | `number \| null` | 0〜10 の整数。判定不能なら `null` |
| `value` | `number \| null` | 判定に使った算出値。表示用        |

> **金額は銭単位の整数で受け取り、途中で浮動小数点に落とさない。**
> 比率の算出でのみ小数を使い、**丸めるのは表示層の1箇所だけ**。

## 3. 計算式

$$\text{CAGR} = \left( \frac{\text{現在の売上高}}{\text{5年前の売上高}} \right)^{\frac{1}{5}} - 1$$
「業績」ブロックの `売上高` 列から取る（`scoring-requirements.md` §2.4）。

## 4. スコア判定

区分の解釈は **「下限以上、上限未満」**（[§0.1](../../01_requirements/scoring-requirements.md)）。
最上位行のみ「下限以上」、最下位行のみ「上限以下」。

| 下限 | 上限   | 点数 |
| :--- | :----- | :--- |
| 20%  | 以上   | 10   |
| 16%  | 20%    | 9    |
| 14%  | 16%    | 8    |
| 12%  | 14%    | 7    |
| 10%  | 12%    | 6    |
| 8%   | 10%    | 5    |
| 6%   | 8%     | 4    |
| 4%   | 6%     | 3    |
| 2%   | 4%     | 2    |
| 0%   | 2%     | 1    |
| —    | 0%以下 | 0    |

## 5. 例外処理

| 状況                     | スコア  | 画面表示                    |
| :----------------------- | :------ | :-------------------------- |
| いずれかが `null`        | `null`  | `—`（データなし）           |
| 5年前の売上高が 0        | `null`  | `—`（ゼロ除算）             |
| 5年前の売上高が負        | `null`  | `—`（成長率を定義できない） |
| 成長率が 0% 以下（減収） | **0点** | 算出値 / 0点                |

**`null`（判定不能）と 0点は別物。** 画面には `0` ではなく `—` を出す。

> 総合点の集計時のみ `null` を 0点として合算する（[§0.5](../../01_requirements/scoring-requirements.md)。
> 分母は常に 100点）。総合点の隣に有効指標数を併記すること。

## 6. 受入基準

実装時にこの4系統をすべてテストすること。1つでも欠けたら未完了とする。

### 6.1 境界値ちょうど

- [ ] `20.0%` → **10点**
- [ ] `19.999...%` → 9点
- [ ] `0.0%` → **0点**（1点ではない）
- [ ] `0.001%` → 1点

### 6.2 負の値

減収（CAGR が負）は最下段「0%以下 → 0点」。表に明示があるので §0.3 の対象外。

### 6.3 無配・0

売上高 0 は現実には異常値。基準年が 0 ならゼロ除算で `null`。

### 6.4 データ欠損

`null` を返す条件: いずれかの入力が `null`、または5年前の売上高が 0 以下。

- [ ] 上記の各条件で `null` が返る（**0 が返らない**）
- [ ] 画面表示が `—` になる（`0` や `0.00%` にならない）

## 7. 参考資料との差分

参考資料 `high_dividend_10_indicators_scoring.md`（YouTube「高配当ラボ」由来）の
**⑦（売上高5年CAGR）** に相当する。

最上位（20%以上 → 10点）のみ一致。

| 項目      | 本仕様（SSoT） | 参考資料    |
| :-------- | :------------- | :---------- |
| 9点の下限 | 16%            | **15%**     |
| 8点の区間 | 14〜16%        | **10〜15%** |
| 7点の区間 | 12〜14%        | **8〜10%**  |
| 6点の区間 | 10〜12%        | **7〜8%**   |
| 5点の区間 | 8〜10%         | **6〜7%**   |
| 4点の区間 | 6〜8%          | **5〜6%**   |
| 3点の区間 | 4〜6%          | **3〜5%**   |
| 2点の区間 | 2〜4%          | **2〜3%**   |
| 1点の区間 | 0〜2%          | **1〜2%**   |
| 0点       | 0%以下         | **1%未満**  |

**影響:**

**10点以外ほぼ全行が相違。** 参考資料のほうが緩い。
例: 売上成長 9% は SSoT で 5点、参考資料で 7点。**2点差**。

> 🔴 **未決。** どちらを採用するかは決まっていない。本仕様は SSoT のまま据え置いている。
> 判断は [scoring-source-comparison.md](../../01_requirements/scoring-source-comparison.md) で一括して行う。
