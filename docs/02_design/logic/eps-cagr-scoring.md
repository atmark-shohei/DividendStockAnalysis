# EPS の5年 CAGR スコアリング 仕様書（指標④）

> **スコア表の原典:** [scoring-requirements.md](../../01_requirements/scoring-requirements.md) の指標④（SSoT）
> **出典の相違と決定:** [scoring-source-comparison.md](../../01_requirements/scoring-source-comparison.md)
> 参考資料との差分と、それに対する決定は §7 にある。

## 1. 概要

- **分類:** 増配余力

1株あたり純利益の年平均成長率。配当性向を据え置いたまま増配するには EPS 成長が要る。

## 2. 入出力

**入力**

| 項目         | 型                   | 単位       | 備考                      |
| :----------- | :------------------- | :--------- | :------------------------ |
| `epsHistory` | `(number \| null)[]` | 銭（整数） | 年度降順の EPS。最低6年分 |

**出力**

| 項目    | 型               | 備考                              |
| :------ | :--------------- | :-------------------------------- |
| `score` | `number \| null` | 0〜10 の整数。判定不能なら `null` |
| `value` | `number \| null` | 判定に使った算出値。表示用        |

> **金額は銭単位の整数で受け取り、途中で浮動小数点に落とさない。**
> 比率の算出でのみ小数を使い、**丸めるのは表示層の1箇所だけ**。

## 3. 計算ロジック

一過性の特別損益をならすため、**直近3年の中央値**と**5年前から遡った3年の中央値**を使って
成長率を算出する（`scoring-requirements.md` ④）。単年同士の比較をしない。

## 4. スコア判定

区分の解釈は **「下限以上、上限未満」**（[§0.1](../../01_requirements/scoring-requirements.md)）。
最上位行のみ「下限以上」、最下位行のみ「上限以下」。

| 下限 | 上限   | 点数 |
| :--- | :----- | :--- |
| 20%  | 以上   | 10   |
| 16%  | 20%    | 9    |
| 14%  | 16%    | 8    |
| 12%  | 14%    | 7    |
| 10%  | 12%    | 6    |
| 8%   | 10%    | 5    |
| 6%   | 8%     | 4    |
| 4%   | 6%     | 3    |
| 2%   | 4%     | 2    |
| 0%   | 2%     | 1    |
| —    | 0%以下 | 0    |

## 5. 例外処理

| 状況                                   | スコア  | 画面表示                    |
| :------------------------------------- | :------ | :-------------------------- |
| EPS 履歴が6年分に満たない              | `null`  | `—`（データ不足）           |
| 中央値の算出に必要な年に `null` がある | `null`  | `—`                         |
| 5年前側の中央値が 0                    | `null`  | `—`（ゼロ除算）             |
| 5年前側の中央値が負                    | `null`  | `—`（成長率を定義できない） |
| 成長率が 0% 以下                       | **0点** | 算出値 / 0点                |

**`null`（判定不能）と 0点は別物。** 画面には `0` ではなく `—` を出す。

> 総合点の集計時のみ `null` を 0点として合算する（[§0.5](../../01_requirements/scoring-requirements.md)。
> 分母は常に 100点）。総合点の隣に有効指標数を併記すること。

## 6. 受入基準

実装時にこの4系統をすべてテストすること。1つでも欠けたら未完了とする。

### 6.1 境界値ちょうど

- [ ] `20.0%` → **10点**
- [ ] `19.999...%` → 9点
- [ ] `16.0%` → **9点**
- [ ] `0.0%` → **0点**（1点ではない）
- [ ] `0.001%` → 1点

### 6.2 負の値

成長率が負のときは最下段「0%以下 → 0点」。**基準年の EPS が負**のときは成長率を
定義できないので `null`（0点ではない）。この2つを混同しないこと。

### 6.3 無配・0

EPS が 0 の年があっても中央値には算入する。基準年側の中央値が 0 になったらゼロ除算で `null`。

### 6.4 データ欠損

`null` を返す条件: 履歴が6年に満たない、必要な年に `null` がある、基準年側の中央値が 0 または負。

- [ ] 上記の各条件で `null` が返る（**0 が返らない**）
- [ ] 画面表示が `—` になる（`0` や `0.00%` にならない）

## 7. 参考資料との差分と決定

参考資料 `high_dividend_10_indicators_scoring.md`（YouTube「高配当ラボ」由来）の
**④（EPSの5年CAGR）** に相当する。

最上位（20%以上 → 10点）のみ一致。

| 項目      | 原典（SSoT） | 参考資料    |
| :-------- | :----------- | :---------- |
| 9点の下限 | 16%          | **15%**     |
| 8点の区間 | 14〜16%      | **12〜15%** |
| 7点の区間 | 12〜14%      | **10〜12%** |
| 6点の区間 | 10〜12%      | **8〜10%**  |
| 5点の区間 | 8〜10%       | **6〜8%**   |
| 4点の区間 | 6〜8%        | **4〜6%**   |
| 3点の区間 | 4〜6%        | **3〜4%**   |
| 2点の区間 | 2〜4%        | **1〜3%**   |
| 1点の区間 | 0〜2%        | **行なし**  |
| 0点       | 0%以下       | **1%未満**  |

**影響:**

**10点以外ほぼ全行が相違。** 参考資料のほうが緩い（同じ成長率でより高い点が付く）。
例: EPS 成長 13% は SSoT で 7点、参考資料で 8点。

### 決定（2026-07-27）

✅ **正典据え置き。** 相違は「参考資料のほうが緩い」方向で一貫しており、
**どちらが正しいかではなく、どれだけ辛く採点したいかの問題**と判断した。
高配当銘柄の絞り込みでは辛い側を既定とするほうが安全。⑦⑧ も同じ扱い。

## 8. 既存実装との対応

`getEpsCagrScore()` として実装あり。ただし中央値補正をしておらず**単年同士で比較**している。

旧実装（[reference/legacy-web/](../../../reference/legacy-web/README.md)）は**再利用しない**（T-008）。
挙動の記録としてのみ参照する。
