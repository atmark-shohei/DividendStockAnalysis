# コードレビュー出力フォーマット（BE/FE 共通）

be-reviewer / fe-reviewer の出力はこのフォーマットに従う。

> **重要度（レベル）は付与しない**。レビュー指摘は **全件、担当者が確認・対応する** 前提のため、優先度マーク（Critical / High / Medium / Low 等）は使用しない。

## 指摘1件あたりのフォーマット

```markdown
### <指摘番号>

| 項目                 | 内容                                                             |
| -------------------- | ---------------------------------------------------------------- |
| **不具合内容**       | <1行で要約>                                                      |
| **不具合詳細**       | <詳細な説明。何が問題で、なぜ問題なのか>                         |
| **改善案**           | <具体的な修正方法。「何を」「どのファイルで」「どう修正するか」> |
| **対象資料・コード** | <ファイルパス:行番号、または参照すべき設計書パス>                |
```

## 全体構造

```markdown
## <BE/FE> コードレビュー結果

### サマリ

| #   | 区分                         | 実装コード | テストコード | 計  |
| --- | ---------------------------- | ---------- | ------------ | --- |
| 1   | 指摘                         | N          | N            | N   |
| 2   | 推測仕様（設計書に記載なし） | N          | N            | N   |

### 指摘一覧

（全件記載。重要度区分なし。検出順または関連グループ単位で並べる）

#### CR-1

| 項目                 | 内容                                                                                                                        |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **不具合内容**       | ファクトリ外での `as Sen` キャスト                                                                                          |
| **不具合詳細**       | usecase 内で `value as Sen` を直接書いている。branded type の保証（銭単位整数）が破られ、浮動小数点値が金額として流入しうる |
| **改善案**           | `createSen()` / `senFromYen()` 経由に置き換える。変換不能な入力は Result のエラーで返す                                     |
| **対象資料・コード** | src/usecase/scoring/calc-total.ts:L42                                                                                       |

#### CR-2

...（全件記載）

### 推測仕様（人間確認必須）

| #   | ファイル | 行  | 推測内容 | 推測根拠 | docs の記載 |
| --- | -------- | --- | -------- | -------- | ----------- |

> **Manager への指示**: このセクションに1件以上ある場合、**人間に確認** すること。

### 総評

- **品質評価**: <良好 / 中程度 / 要改善>
- **推測仕様**: <N 件>
```

> **注意**: テスト実行・Lint 実行の結果は本フォーマットに含めない。コマンド実行はメインセッション（Manager）が別途実施する。
