# FE コードレビュー チェックリスト

ベース観点 = `ai/rules/fe/` 全ファイル（coding-standards / test-patterns）。本ファイルはレビュー固有観点を集約した正本。

## 1. 責務・構成

- [ ] スコアリング・金額の計算ロジックが FE に書かれていないか
- [ ] API との型契約が `docs/02_design/api/` と一致しているか

## 2. `null` と 0 の表示（最重要）

- [ ] 判定不可指標（`score: null`）が `—` か「データなし」で表示されているか（0 表示になっていないか）
- [ ] `score ?? 0` / `Number(score)` 等の null → 0 変換が表示系に紛れ込んでいないか
- [ ] レーダーチャートで `null` 指標が「0 の頂点」として描画されていないか（欠損の扱いが `docs/02_design/ui/` と一致しているか）

## 3. 金額・日付の表示

- [ ] 銭 → 円の表示変換が正しいか。FE で浮動小数点の金額計算をしていないか
- [ ] JST 変換が表示層に閉じているか（UTC のまま表示していないか）
- [ ] 表示フォーマットの変更に対応するテストがあるか

## 4. テスト

- [ ] テストが `tests/` にミラー配置されているか
- [ ] FE テストが unit 系統で回っているか
- [ ] `null` → `—` 表示のテストがあるか
- [ ] 金額・日付表示の境界値テスト（0円 / 端数 / 日跨ぎ）があるか
- [ ] 実 API を叩くテストがないか。モックが実物サンプル由来か

## 5. ドキュメント整合

- [ ] 表示ラベル・用語が `docs/glossary.md` と一致しているか
- [ ] 実装が `docs/02_design/ui/` と矛盾していないか（矛盾があれば指摘として報告）
- [ ] 設計書に記載のない仕様が推測で実装されていないか（あれば「推測仕様」として報告）
