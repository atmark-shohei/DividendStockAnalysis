# FE コーディング規約（frontend/）

対象: `frontend/` 配下。React 19 / Vite / Recharts 3 / TypeScript 5.9。

## 1. 責務

- FE は表示とユーザー操作のみ。**スコアリング・金額の計算ロジックを FE に書かない**（domain の結果を表示する）
- API との型契約は `docs/02_design/api/` の設計書に従う

## 2. `null` と 0 の表示（このプロジェクトの中心要件）

- **「データなし」を 0 と表示しない**。個別指標が `null`（判定不可）の場合は `—` か「データなし」と明示する
- `MetricScore` の `score: null` を 0 に変換するコード（`score ?? 0`、`Number(score)` 等）を表示系に書かない
- 0 に丸めてよいのは総合点の集計時だけ（それは BE domain の責務）
- レーダーチャート（Recharts）でも `null` 指標は「0 の頂点」として描画しない。欠損として扱う方法は `docs/02_design/ui/` の設計書に従う

## 3. 金額・日付の表示

- 金額は銭単位整数 `Sen` で受け取り、表示時に円へ変換する。**FE で浮動小数点の金額計算をしない**（表示フォーマットのみ）
- 日時は UTC で受け取り、**表示層でのみ JST に変換する**
- 金額や日付の表示ミスが許されないプロジェクトである。表示フォーマットの変更には必ずテストを付ける

## 4. 命名・その他

- 型名・関数名・表示ラベルの用語は `docs/glossary.md` に従う
- マジックナンバー禁止
- 実装と設計書（`docs/02_design/ui/`）が食い違ったら、どちらが正しいかを確認してから修正する。実装が終わったら設計書も更新する
