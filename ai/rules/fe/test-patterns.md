# FE テストパターン（Vitest）

## 1. 置き場所と系統

- テストは `frontend/` に colocate せず、`tests/` 配下にミラーする（フォルダ実名は vitest 設定で確認）
- FE のテストは **unit 系統**（`vitest.unit.config.ts`）で回す。Cloudflare ランタイム不要
- コンポーネントテストの手段（React Testing Library 等）はリポジトリ実体を確認して既存パターンを踏襲する。独自判断でテストライブラリを追加しない

## 2. スタイル

- table-driven を基本とし、テスト名で「何が壊れたか」が分かるようにする
- **テストで実 API を叩かない**。モックは実物の API レスポンスサンプルから作る

## 3. 必須の観点

- **`null` → `—` 表示**: 判定不可指標（`score: null`）が `—` または「データなし」と表示され、**0 と表示されない**ことを検証する
- **金額表示**: 銭 → 円変換の境界値（0円 / 端数）を検証する
- **日付表示**: UTC → JST 変換（日跨ぎになる時刻）を検証する
- 表示フォーマットを変更したら、対応するテストを必ず追加・更新する

## 4. 完了条件

`ai/rules/be/test-patterns.md` §5 と同じ（`npm test` / `npm run typecheck` / `npm run lint` 全パス + 対応テストの存在 + 証拠添付）。
